# 左侧读法

左侧的本质是**在证据不全时承担不确定性**。读左侧只做一件事：按顺序过三层滤网，任一层不过，结论就是「观察」，不是「买点」。

## 0. 顺序不能换
情绪 → 催化 → 量价。顺序反了，就会拿着一张好看的 K 线图去接退潮期的下跌。

## 1. 第一层：情绪周期（市场级）
- 先判断市场在冰点、修复、发酵、高潮还是退潮。左侧只在冰点末期到修复初期有意义。
- 退潮期里所有「超跌」都还能更超跌，此时左侧不是机会，是逆势。
- 情绪层取不到就明说未取到，不要用个股资金流或涨跌幅冒充市场情绪。

## 2. 第二层：催化
- 要能说出「为什么会涨」的具体链条：涨价、政策、产能、订单、事件。
- 只有跌幅没有逻辑的票，是下跌中继，不是左侧。
- 催化未取到就写「催化未知」——这不等于没有催化，只等于没验证。

## 3. 第三层：量价结构
- 看阶段：止跌构建 → 筹码沉淀 → 终极测试 → 突破。左侧要的是前两段的证据，不是第四段的涨幅。
- 地量：缩量到极致说明抛压枯竭，是必要不充分条件。
- 放量不破前低：放量而价格守住前低，说明有资金在接，这是最关键的一条。
- 均线走平：中期均线由下行转走平，才说明下跌动能消失；均线仍在下行时的反弹都是反抽。
- 弹簧试探（假破位后快速收回）比横盘更可信，但要看收回当日的量能是否配合。

## 4. 便宜 ≠ 买点
- 便宜是相对估值或相对跌幅；买点是「抛压耗尽 + 有资金接 + 有逻辑」三者同时出现。
- 不许用「无主力、资金流出」直接否掉一只左侧票：左侧本来就没有主力，等主力进场时价格已不在左侧。
- 同样不许把「跌得够多」当买入理由。

## 5. 确认与失效
- 确认：地量之后放量不破前低、均线走平、筹码在低位单峰集中、催化开始被市场提及。
- 失效：放量跌破前低、缩量阴跌始终无地量、均线继续下行、逻辑被证伪（涨价停了、订单丢了）。
- 三层里哪一层没过就写哪一层，不要把「未取到」写成「不成立」，也不要反过来。
