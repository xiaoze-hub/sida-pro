# 分时读法（内外盘 / 量能 / 挂撤单）

**1. 先定位，再解释**：日内位置（0=最低，100=最高）+ 是否站在均价线(VWAP)上。
高位放量滞涨 = 派发嫌疑；低位放量破均价 = 恐慌出逃；低位缩量横盘 = 洗盘待变。

**2. 内盘外盘七口诀**（位置优先，量价其次）：
- 外盘大 + 涨 + 放量 = 真金进攻
- 内盘大 + 跌 + 放量 = 主力撤退
- 外盘大 + 跌 + 高位 = 诱多出货
- 内盘大 + 涨 + 低位 = 压盘吸筹
- 内外相当 + 横盘 = 多空平衡
- 内外双小 = 控盘洗盘
- 内外双大 + 不动 = 对倒造假
只报「占比 + 位置 + 量能」三项，不要只念外盘大于内盘就当利好。

**3. 分时量三时点**：开盘 30 分钟（定当日强弱）、午后 13:30-14:00（定是否延续）、尾盘 30 分钟（定次日预期）。
某时段量占比 >50% 而价格没走出去 = 该时段承接不足。

**4. 均价线是当天多空成本**：站上占比 <40% 说明全天被均价压制；尾盘拉回均价上方才算修复。

**5. 挂单/撤单**：买卖压比 >1 只是「挂着的多」，不等于买盘真实；要结合撤单率——
买盘撤单率高（>60%）= 托单是假的；卖盘撤单率高 = 压单也是假的。撤单率是 TQ 会话累计值，收盘后不代表次日。

**6. 数字纪律**：分时画像工具返回的每个数字都要照抄，缺的写「未取到」，禁止按K线形态推分时结论。
