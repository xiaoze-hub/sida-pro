# 集合竞价读法

1. **先确认时点**：9:15–9:20 可撤单，9:20–9:25 不可撤单，9:25 出开盘价。9:25 前问"竞价怎么样"要说明"竞价尚未定型"。
2. **看三件事**：开盘涨幅（OpenZAF）、竞价成交额（OpenAmo）、一字买量（OpenZTBuy）。只给涨幅不给成交额 = 没信息量。
3. **逐票优先**：问某只票必须逐票取数（scene=watchlist/symbols），不要用全市场最强榜推断"没有竞价"。
4. **爆量判据**：竞价成交额 ÷ 昨日同期 > 2 且 开盘涨幅 > 3% → 抢筹；涨幅高但成交额小 → 空心高开。
5. **撤单真伪**：9:20 前撤单率高不代表出货，要看 9:20–9:25 的封单是否回补。
6. 取不到数据就写"无竞价快照"，**不要**推断为"没有强度"。
