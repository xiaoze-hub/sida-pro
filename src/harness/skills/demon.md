# 妖股读法

妖股不是涨得快的成长股，是**情绪载体**。读它只回答四件事：几板、封得死不死、故事在第几段、谁在接力。

## 1. 身位：先定位，再谈强弱
- 第几板决定它是不是市场最高标；「市场最高标」与「同题材最高标」是两回事，两个都要给。
- 同题材的板数梯队要列全：谁卡位、谁掉队、有没有断层。断层是退潮先兆，不是「洗盘」。
- 身位越高容错越低：高位板的风险不来自基本面，来自下一天没人接。

## 2. 封单比：看相对量级，不看绝对金额
- 封单额要除以流通市值（或流通股本）才有可比性；不换算的封单额只是噪音。
- 早盘快速封住且封单稳定，与尾盘偷袭回封，是两种资金态度。
- 封单厚但当日反复开板，说明有资金在借封单出货。

## 3. 炸板：次数与回封时间比「炸没炸」更重要
- 一次炸板后快速回封 = 分歧转一致；反复炸板 = 承接在衰竭。
- 炸板的分时低点与回封时点，是区分「洗盘」与「派发」的直接证据。
- 尾盘炸板不回封按失败处理，不要用「洗盘」美化。

## 4. 题材周期四阶段
- 启动：一两只先动，市场无共识。身位便宜，但故事未被验证。
- 发酵：涨停家数扩散、跟风出现，中军与龙头开始分层。这一段最容易做错的是追后排。
- 高潮：全市场都知道、后排补涨、龙头缩量一字。风险最高，人多的地方最贵。
- 退潮：连板高度下移、炸板率上升、昨日涨停今日大面积回落。不接力。
- 阶段判断落在「涨停家数、连板高度、炸板率、昨日涨停溢价」四个方向的相对变化上，不单看指数。

## 5. 游资席位：看行为，不看名号
- 知名席位买入不等于继续涨，要看它是首板介入还是高位接力、单向买入还是有对倒。
- 同席位反复出现在同一题材 = 主线资金；散在多个题材 = 打一枪就走。
- 席位数据缺失就写缺失，不要用主力净流入替代。

## 6. 接力条件与失效信号
- 接力成立：题材在发酵或高潮前段、身位是梯队最高或次高、封板质量未恶化、有新增资金而非存量对倒。
- 失效信号：晋级失败且次日不修复、封单比显著萎缩、同题材断层、题材进入退潮、龙头被卡位。
- 失效时要直接说「身位已破」，不要转去谈估值与支撑位——那是趋势票的语言。
