## 四、邮箱注册 + API Key 控制台 (v0.10.0)

### 邮箱验证码
- `POST /api/auth/send-code`: 发送验证码(5分钟过期, 每邮箱每分钟1次)
- 注册强制验证码校验
- `POST /api/auth/login-by-email`: 邮箱+验证码登录
- 前端三模式 Tab: 密码登录/注册/验证码登录
- SMTP 未配置时开发模式打印验证码

### API Key 控制台 (`/api-keys`)
- 列表: prefix/tier/status/创建时间/最后使用
- 操作: 复制/重置/删除(均有确认)
- 用量: 今日/7天/30天统计
- 创建: 新 Key 明文只显示一次

### 智能体一键安装
- `GET /api/skills/install.sh`: shell 脚本
- `GET /api/skills/config`: 用户 skill 配置 JSON
- ApiKeys 页生成可复制的 curl 命令
