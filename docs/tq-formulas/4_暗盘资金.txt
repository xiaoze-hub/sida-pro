{===============================================================
 SIDA-Pro 策略指标 · 通达信(TDX) 公式包
 公式名称: 暗盘资金            [技术指标公式 · 副图]
 换算来源: src/core/ohlc_dark.py (OHLC 分摊) + src/core/dark_pool_flow.py
 算法(K线形态分摊, 同花顺 APZJ 对照口径):
     典型价 tp = (H+L+2C)/4
     成交额 amt = 成交量(股) × tp        注: TDX 的 VOL 单位是"手", 故 amt = VOL*100*tp
     收盘位置 pos = (C-L)/(H-L)          一字板(H=L): C>O 取 1, C<O 取 0, C=O 取 0.5
     流入 = amt*pos ; 流出 = amt*(1-pos) ; 净额 = 流入-流出
 单位:    输出为"亿元"(除以 1E8), 便于副图显示。
 语法基准: 通达信官方公式系统函数表 help.tdx.com.cn/gspt
 安装:    公式管理器 -> 技术指标公式 -> 新建 -> 画线方法=副图 -> 粘贴 -> 测试公式
 ⚠️ 重要:  OHLC 分摊是"对照项/近似", 与逐笔真值有偏差(妖股大振幅日误差可达数十倍)。
          红柱=净流入 / 绿柱=净流出; 仅供形态参考, 绝不可作为下单依据。
===============================================================}

TP:=(H+L+2*C)/4;                                 {典型价}
AMT:=VOL*100*TP;                                 {成交额(元): VOL(手)*100(股/手)*tp}
POS:=IF(H>L,(C-L)/(H-L),IF(C>O,1,IF(C<O,0,0.5)));{收盘位置; 一字板按开收定多空}
DBUY:=AMT*POS;                                   {分摊流入额(元)}
DSELL:=AMT*(1-POS);                              {分摊流出额(元)}
DPJ:=(DBUY-DSELL)/100000000;                    {暗盘净额(亿元)}

暗盘资金:DPJ,NODRAW;                            {数值可读, 不画线}
STICKLINE(DPJ>0,0,DPJ,2.5,0),COLORRED;          {红柱: 净流入}
STICKLINE(DPJ<0,0,DPJ,2.5,0),COLORGREEN;        {绿柱: 净流出}
