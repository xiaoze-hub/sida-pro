{===============================================================
 SIDA-Pro 策略指标 · 通达信(TDX) 公式包
 公式名称: AI机构活跃度        [技术指标公式 · 副图]
 换算来源: src/core/ai_activity.py
           + src/core/decision_pioneer.py::compute_institution_activity
 算法:    活跃度 = max(7 因子) × 1.2        (因子均为"百分数")
          7 因子 = 上影 / 下影 / 实体+上影 / 实体+下影 / 上影+下影 / 涨幅 / 高开
 阈值:    生命线 1.56 / 强势线 3.00 / 大牛线 6.00 / 更佳线 12.00 (SIDA 默认值)
 语法基准: 通达信官方公式系统函数表 help.tdx.com.cn/gspt
 安装:    公式 -> 公式管理器(Ctrl+F) -> 技术指标公式 -> 选子类 -> 新建
          -> 画线方法=副图 -> 粘贴本文件 -> 测试公式 -> 确定
 用途:    复盘/观察, 不构成交易建议。
===============================================================}

{--- 7 因子, 与 ai_activity.ACTIVITY_FACTORS 逐项对应(顺序勿改) ---}
SY:=(H-MAX(C,O))/MAX(C,O)*100;   {1 上影}
XY:=(MIN(C,O)-L)/L*100;          {2 下影}
TT:=(C-O)/O*100;                 {  实体(带符号; 阴线为负, 与 SIDA 一致, 勿加 ABS)}
ZF:=(C-REF(C,1))/REF(C,1)*100;   {6 涨幅}
GK:=(O-REF(C,1))/REF(C,1)*100;   {7 高开}
F3:=TT+SY;                       {3 实体+上影}
F4:=TT+XY;                       {4 实体+下影}
F5:=SY+XY;                       {5 上影+下影(全幅)}

{--- 活跃度 = max(7 因子) × 1.2 ---}
{注: 上影/下影恒 >= 0, 故活跃度恒 >= 0, 不会出现负柱。}
MX:=MAX(MAX(MAX(SY,XY),MAX(F3,F4)),MAX(MAX(F5,ZF),GK));
活跃度:MX*1.2,COLORWHITE;

{--- 阈值水平线 ---}
生命线:1.56,COLORLIGRAY;
强势线:3.00,COLORYELLOW;
大牛线:6.00,COLORRED;
更佳线:12.00,COLORMAGENTA;

{--- 三色柱(紫/红/绿) ---}
STICKLINE(活跃度>=6,0,活跃度,2.5,0),COLORMAGENTA;            {紫: 大牛线及以上}
STICKLINE(活跃度>=3 AND 活跃度<6,0,活跃度,2.5,0),COLORRED;   {红: 强势线~大牛线}
STICKLINE(活跃度<3,0,活跃度,2.5,0),COLORGREEN;              {绿: 强势线以下}
