 SIDA-Pro 策略指标 · 通达信(TDX) 公式包
 公式名称: 牛熊线              [技术指标公式 · 主图叠加]
 换算来源: src/core/niuxiong_line.py
 算法:    牛线 = WMA(C,20)   20 日加权均线(线性权重 1..n)
          马线 = MA(C,5)     5 日简单均线
          买卖线 = MA(C,30)  30 日简单均线(SIDA 逆向近似默认值)
          牛线上穿买卖线 = 金叉 -> B;  下穿 = 死叉 -> S。
 铁律:    B(买)=红 / S(卖)=绿。
 语法基准: 通达信官方公式系统函数表 help.tdx.com.cn/gspt
 安装:    公式管理器 -> 技术指标公式 -> 新建 -> 画线方法=主图叠加 -> 粘贴 -> 测试公式
 用途:    客观信号标注, 不构成交易建议。
===============================================================}

{--- 三线 ---}
牛:WMA(C,20),COLORRED;       {牛线 = 20日加权均线}
马:MA(C,5),COLORWHITE;       {马线 = 5日均线}
买卖线:MA(C,30),COLORYELLOW; {买卖线 = 30日均线}

{--- 金叉/死叉 ---}
JB:=CROSS(牛,买卖线);        {牛线上穿买卖线 = 金叉}
SC:=CROSS(买卖线,牛);        {牛线下穿买卖线 = 死叉}

DRAWTEXT(JB,L*0.97,'B'),COLORRED;    {买 红 B}
DRAWTEXT(SC,H*1.03,'S'),COLORGREEN;  {卖 绿 S}
