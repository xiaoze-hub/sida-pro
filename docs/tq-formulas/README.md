# SIDA-Pro 策略指标 → 通达信(TDX) 公式包

> **基线标识**: SIDA-Pro `main` @ `3391ee0` (v0.13.64, 2026-10-11 发布)
> **审计/换算对象**: `src/core/ai_activity.py` · `decision_pioneer.py` · `trend_pilot_line.py`
> · `niuxiong_line.py` · `ohlc_dark.py` · `dark_pool_flow.py` · `gs_strategy.py` · `limit_up_strength.py`
> · `thresholds.py`
> **覆盖范围**: 上述 8 个策略模块的**指标算法**被翻译为 TDX 公式源码(6 个 `.txt`);
> **未覆盖**: `dark_flow_fusion`(需 `.tck` 委托号)、`tick_super_level1`、`resonance` 状态机、
> `market_regime`、前端图层与 push/API 链路 —— 这些依赖逐笔/L2 数据或跨模块状态, TDX 公式无法表达。

本目录把 SIDA 的策略体系**翻译成通达信公式系统的源码包**, 供用户在客户端
`公式管理器` 里新建/粘贴/上图使用。**每个公式都是一份可独立粘贴的 `.txt` 源码**, 附参数表、
安装步骤与**与 SIDA 实现的差异声明**。

## 1. 语法基准(权威来源)

所有函数名、参数个数、绘图函数签名**逐条对照**以下权威来源核对, **不凭记忆编写**:

- 通达信官方公式系统文档: `help.tdx.com.cn/gspt`(函数列表 / 基本概念 / 公式系统 PDF)
- 公开函数手册(对拍): zcym.net 函数大全、agudashi.cn 函数帮助、chanluns.com 函数库

已核对并使用的关键函数:

| 函数 | 签名 / 说明 | 出处 |
|---|---|---|
| `MA(X,N)` | N 日简单移动平均 | 官方函数表 |
| `EMA(X,N)` | 指数移动平均, `Y=Y'+(X-Y')*2/(N+1)` | 官方函数表 |
| `WMA(X,N)` | 加权移动平均, `Yn=(1*X1+…+n*Xn)/(1+…+n)` | 官方函数表 |
| `CROSS(A,B)` | A 上穿 B 返回 1 | 官方函数表 |
| `MAX/MIN(A,B)` `ABS(X)` `IF(X,A,B)` | 2/2/1/3 参 | 官方函数表 |
| `REF(X,N)` `COUNT(X,N)` `HHV/LLV(X,N)` | 2 参 | 官方函数表 |
| `STICKLINE(COND,P1,P2,WIDTH,EMPTY)` | 柱状线; EMPTY=0 实心 | 官方函数表 |
| `DRAWICON(COND,PRICE,TYPE)` / `DRAWTEXT(COND,PRICE,TEXT)` | 图标 / 文字标记 | 官方函数表 |
| `ZTPRICE(REF(C,1),R)` / `DTPRICE(...)` | 计算涨停/跌停价 | 官方函数表 |
| `FINANCE(40)` 流通市值(元) / `FINANCE(46)` 自由流通股本(股) | 财务函数 | 官方函数表 |
| `DYNAINFO(88)` 封单额(元, 仅最新一根) / `DYNAINFO(90)` 连板天数 | 即时行情 | 官方函数表 |
| `BARSLASTCOUNT(X)` | 条件连续成立次数 | 官方函数表 |
| `CODELIKE/NAMELIKE/NAMEINCLUDE(S)` | 代码/名称模糊匹配 | 公开手册 |
| `GPJYVALUE(ID,N,TYPE)` | 股票交易类数据(需专业财务数据/云数据) | 公开手册 |
| 颜色 `COLORRED/COLORGREEN/COLORMAGENTA/COLORYELLOW/…`、线型 `STICK/LINETHICK/NODRAW/COLORSTICK…` | 线形与颜色属性 | 官方函数表 |

**语法要点**(写错会导致粘贴报错, 已逐条遵守):
- 注释用 `{ }`(英文花括号), **不可嵌套**; 语句以**英文** `;` 结尾;
- 赋值 `:=`(不输出) / `:`(输出); 变量名不可数字开头、不可与函数同名;
- 运算符 `AND/OR/NOT` 与 `+ - * / > < >= <= = <>(&& ||)`;
- 标点、括号、逗号必须是**英文半角**(文内已剔除全部中文标点)。

## 2. 安装步骤(通用)

### 2.1 技术指标公式(公式 1~5)
1. 打开客户端 → 菜单 `公式` → `公式管理器`(快捷键 **Ctrl+F**);
2. 左树展开 `技术指标公式` → 选一个子类(如「均线型」/「其他类型」) → 点右侧 **新建**;
3. 填 **公式名称**(如 `AI活跃度`)与 公式描述;
4. **画线方法**: 按上表选 `副图`(1、4) 或 `主图叠加`(2、3、5);
   - 副图类可顺手在 **坐标线位置** 填 `1.56;3;6;12` 得到参考横线;
5. 用记事本打开对应 `.txt`(**UTF-8**), 全选复制 → 粘进编辑器区;
6. 点 **测试公式** → 显示「测试通过」→ 点 **确定** 保存;
7. K 线界面键盘输入公式名(如 `AI活跃度`)回车即可调出。

### 2.2 条件选股公式(公式 6)
1. `公式管理器` → 左树 `条件选股公式` → `其他类型` → **新建**;
2. 粘贴 `6_涨停强度选股.txt` → `测试公式` → 确定;
3. 调出: 菜单 `选股器` → `条件选股` → 选中本公式 → `执行选股`。
   - ⚠️ 条件选股公式**只能有 1 个输出**(本文件已保证: 除末行 `XG:` 外全部用 `:=`)。

### 2.3 关于参数(可选)
本包**默认把周期写死为 `:=` 赋值**, 因此**粘贴即可用、零配置**。若想在看盘界面用
「调整指标参数」实时改周期, 请用公式编辑器上方的 **参数设置区** 声明参数
(参数名 / 最小值 / 最大值 / 缺省值), 再把源码里对应的 `:=` 常量换成参数名:

| 公式 | 建议参数 | 缺省值 | 范围 |
|---|---|---|---|
| 2 趋势操盘线 | 红 / 黄 / 绿 | 10 / 20 / 60 | 1~250 |
| (同上) | 容差 | 0.01 | 0~0.2 |
| 3 牛熊线 | 牛 / 马 / 买卖线 | 20 / 5 / 30 | 1~250 |

> 说明: 参数**在编辑器的「参数」区设置**, 不是写在代码里(官方文档口径)。
> 本包未使用任何非官方的内联参数声明语法, 以保证「粘贴即通过测试」。

### 公式 1 · AI 机构活跃度(副图)

## 5. 与 SIDA 实现的差异声明(逐条, **禁宣称一致**)

### 5.1 通用
1. **数据基准**: SIDA 跑在 PG 逐笔/日K 多源链(`fetch_bars`)上; TDX 公式跑在**客户端本地行情**上,
   两者 K 线(复权方式、脏值处理)可能不同 → 同一标的数值未必逐位相同。
2. **显示取整**: SIDA 多处 `round(_,3/4)`; TDX 输出全精度。
3. **本包未覆盖**依赖逐笔/L2 的模块(`dark_flow_fusion`、`tick_super_level1`)、
   `resonance` 状态机、`market_regime`、前端图层与 API —— 公式语言无法表达。

### 5.2 公式 1 · AI机构活跃度
- **因子数保留 7 个**(SIDA 口径): 公开资料曾描述为「6 指标」, 但 SIDA 依内部《8问8答》+
  逆向公式钉死为 7(多「上影+下影」全幅项)。本公式**跟着 SIDA 走, 用 7 因子**。
- 实体 `(C-O)/O*100` **带符号**(阴线为负), 与 SIDA 一致; **未加 `ABS`**。
- 上影/下影恒 ≥0 ⇒ 活跃度恒 ≥0(不会出现负柱), 与 SIDA 一致。
- 第 0 根无「昨收」⇒ 活跃度无值(不画); 与 SIDA `activity_series` 首点为 `None` 一致。

### 5.3 公式 2 · 趋势操盘线
- **三线类型是 EMA 近似**: SIDA 明示「同花顺官方未公开三线精确均线类型与周期, 用 EMA 作可调近似」;
  本公式沿用同一 EMA 近似 ⇒ **还原的是 SIDA 的近似实现, 不等于官方操盘线**。
- 长线 `EMA(C,60)` 在不足 60 根 K 线时, TDX 与 SIDA 的「前段无值」行为可能不同(前段数值可能不一致)。
- SIDA 卖点判定里 `rebounded/failed_break` 两式合并后 = `C<绿 AND H≥绿*(1-TOL)`, 本公式已等价化简;
  SIDA 另有 `has_range`(H>L, 排除一字板), 本公式以 `RNG=H>L` 复现。
- **铁律一致**: 买 `▲` 红 / 卖 `▼` 绿。

### 5.4 公式 4 · 暗盘资金(**重要**)
- **该口径本身就是近似(对照项)**: SIDA `ohlc_dark.py` 明示 OHLC 分摊「与逐笔真值有偏差,
  妖股大振幅日误差可达 23 倍」, 且标 `approximation=True`。本公式**继承了这一近似**,
  红绿柱只反映 K 线形态推断的多空,**绝不可作为下单依据**。
- 本公式实现的是 SIDA 的**OHLC 对照口径**, **不是** SIDA 主线的「逐笔拆单识别」
  (`dark_flow_fusion` / `compute_dark_flow_l2`) —— 后者需订单号/L2, TDX 公式做不到。
- 单位: SIDA `amount = 股 × tp`; TDX `VOL` 单位是手, 故用 `VOL*100*tp` 对齐(已验证 Δ=0)。
- 与 SIDA `dark_pool_flow` 的「明盘(官方大单)」部分**无关**: 本公式不含明盘。

### 5.5 公式 5 · GS 波段(**重要**)
- SIDA 的 `compute_gs_signal` 自己就标注为「**仿编版 + 自建结构, 未校准近似**」;
  据研究, 同花顺官方 GS 为**小波变换**类算法, 小波在 TDX 公式语言里**无法表达**。
  ⇒ 本公式还原的是**SIDA 的 BB0/A0 近似实现**, **不是官方 GS**。
- **状态语义缺失**: SIDA 有「信号出现后**次日不消失**(处于 G 区直到 S)」的状态机语义与
  「抖动合并(相邻反向信号 ≤3 天成对丢弃)」。TDX 单公式**无状态记忆**, 只给逐根 `CROSS` 标记,
  故信号条数会**多于** SIDA 去抖后的条数(已用 `denoise=False` 口径验证: 交叉集合逐日一致)。
- TDX 与 SIDA 均以 `BB0` 需 `MA27`(第 28 根起)为前提; 前 27 根前段数值可能不同。

### 5.6 公式 6 · 涨停强度选股(**重要**)
- SIDA 的 `FirstTimeZT`(首封时间)/`OpenTimesZT`(开板次数)来自 **TQ 精确字段**;
  TDX 侧只能近似: 封成比用 `DYNAINFO(88)/FINANCE(40)`,
  **首封时间/开板次数需 `GPJYVALUE`(专业财务数据), 编号未列公开函数表 → 用前必须先「测试公式」**。
- `DYNAINFO(88)` **只有最新一根**(即时行情, 无历史) ⇒ 只能用于「当日选股」, 不能做历史回放。
- **SIDA 的 S/A/B/C 二维矩阵(首封桶 × 封成比档)未整体复刻**: 本公式给的是
  「涨停 + 封成比≥阈值」的**近似筛选**, 只在可选块里演示「早封 + 无炸板」的更强条件。

  创业板/科创板 ST 仍按 20% 处理(与交易所规则一致, 但与简化实现可能不同)。
