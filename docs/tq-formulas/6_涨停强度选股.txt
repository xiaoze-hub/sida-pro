{===============================================================
 SIDA-Pro 策略指标 · 通达信(TDX) 公式包
 公式名称: 涨停强度选股        [条件选股公式]   (仅 1 个输出, 取值为 0/1)
 换算来源: src/core/limit_up_strength.py (首封时间 × 封成比 → S/A/B/C)
 口径对照(SIDA 定义):
     · 封成比 = 封单额 ÷ 流通市值;  档位线 0.01(C/B) / 0.03(B/A) / 0.05(A/S)
     · 首封时间分桶: 竞价(<=09:30) / 早盘(<=10:00) / 盘中(<=14:30) / 尾盘
     · 炸板(开板)>=1 次 -> 强度降一档
 语法基准: 通达信官方公式系统函数表 help.tdx.com.cn/gspt
 安装:    公式管理器 -> 条件选股公式 -> 新建 -> 粘贴 -> 测试公式 -> 确定
          然后在「选股器 -> 条件选股」里勾选本公式执行。
 ⚠️ 差异声明: TQ 的 FirstTimeZT/OpenTimesZT 是**精确值**; TDX 侧只能拿到
     「封单额(DYNAINFO(88), 仅最新一根)」与「流通市值(FINANCE(40))」算封成比,
     「首封时间/开板次数」需专业财务数据(GPJYVALUE, 见文末可选块, 编号未列公开函数表,
     用前务必先『测试公式』验证)。故本公式是**近似筛选**, 不等于 SIDA 的精确分层标签。
 用途:    客观条件筛选, 不构成交易建议。
===============================================================}

{--- 1. 板块自适应涨停幅度 ---}
{ 创业板(30)/科创板(68)=20%; 北交所(8/4)=30%; 主板ST=5%; 其余=10% }
LMT:=IF(CODELIKE('30') OR CODELIKE('68'),0.2,IF(CODELIKE('8') OR CODELIKE('4'),0.3,IF(NAMEINCLUDE('ST'),0.05,0.1)));

{--- 2. 涨停 / 连板 / 炸板 ---}
ZT:=C>=ZTPRICE(REF(C,1),LMT) AND C=H;      {封住涨停(收盘=最高且达涨停价)}
LB:=BARSLASTCOUNT(ZT);                      {连续涨停天数(连板)}
ZB:=H>=ZTPRICE(REF(C,1),LMT) AND C<H;       {曾触涨停但未封住(炸板近似)}

{--- 3. 封成比 = 封单额 / 流通市值 ---}
SEAL:=DYNAINFO(88);                         {封单额(元): >0=涨停状态, <0=跌停状态}
FMC:=FINANCE(40);                           {流通市值(元)}
RATIO:=IF(FMC>0,SEAL/FMC,0);                {封成比}

{--- 4. 选股条件: 今日封住涨停 且 封成比 >= 0.03(SIDA A 档线) ---}
{ 可自行调整阈值: 0.01=C/B线, 0.03=B/A线, 0.05=A/S线 }
XG:ZT AND RATIO>=0.03;

{===============================================================
 可选增强块(默认注释; 需专业财务数据/云数据, 编号未列公开函数表, 用前先测试公式)
  首封:=GPJYVALUE(24,1,2);   首次涨停时间, 形如 92501 表示 09:25:01
  早封:=首封>0 AND 首封<=100000;   <=10:00 表示竞价/早盘桶
  开板:=GPJYVALUE(14,2,2);   开板(炸板)次数
  更强筛选(早封 + 封成比>=0.03 + 无炸板), 替换上面的 XG 行使用:
  XG:ZT AND 早封 AND RATIO>=0.03 AND 开板<=0;
===============================================================}
