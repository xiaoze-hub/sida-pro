# GS 校准报告：自研版 vs 原版视频口径（v1.0）

> 输入：同花顺决策先锋投教视频4段（200s，转写+关键帧已核）+ 上证指数日线501根（2024-08-12→2026-09-03，腾讯`day`接口）。
> 方法：`compute_gs_signals`全序列 + 截尾重算非重绘验证 + 信号位置分位统计（±10日窗）。

## 一、原版口径（视频核定）

- G信号=趋势有望启动、G区间上涨良好；S信号=趋势或将结束、S区间下跌风险大（前置预判，多因子降噪）。
- 原版视觉：**G=绿圆点+字母G（波谷下方），S=红圆点+字母S（波峰上方）**。
- ⚠️ 配色映射：SIDA v0.4.73为G红S绿（A股红涨绿跌惯例），与原版相反；验收以信号位置为准，不以颜色为准。

## 二、实测结果（上证501根，63个信号）

| 检验 | 结果 | 结论 |
|---|---|---|
| 非重绘（截掉末30根重算） | 前段60/60完全一致 | ✅ 非函数，次日不消失 |
| G位置（21日窗分位，越接近0越是谷底） | 中位 **0.53** | ❌ 出在半山腰，非谷底（右侧滞后） |
| S位置（越接近1越是峰顶） | 中位 **0.37** | ❌ 出在半山腰，非峰顶（右侧滞后） |
| 抖动（间隔≤3天） | **16/62**，中位间隔仅7天 | ❌ 震荡市whipsaw严重 |
| 当前 | G区confirmed（08-27 G@3956.57） | 与上证08月初3878企稳回升一致，大方向正确 |

## 三、校准结论

1. **自研裸交叉（BB0/A0）方向正确、位置滞后、震荡抖动**——与第三方评测"GS滞后、第二天才出点"同一根因（日线均线交叉固有），不是实现bug。
2. **维持v0.4.25降级定位**：GS只做趋势过滤（G区/S区），不触发买卖点——本报告数据支撑该决策。
3. 降噪候选（未做，P2）：信号间隔合并（3天内反向忽略）/ ACT≥3门控 / xiaoze裸交叉过滤；做之前先定可接受抖动率。
4. 前端配色须在图例注明"G红S绿为A股惯例映射，原版为G绿S红"，防用户拿原版截图对色。
