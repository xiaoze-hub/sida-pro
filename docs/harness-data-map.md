## 三、全景诊断的问题（用户指出的两条，实测确认）

### 1. 消息面：**已经有数据，但没有进输出结构**
`get_stock_dossier` 的第七~十维已经包含研报、公告、利好、利空（关键词规则筛选、来源可溯）。
但 `deep_diagnosis` 的 `output_sections` 只有
「结论 / 走势与形态 / 筹码结构 / 主力与资金 / 盘口与撤单 / 关键位与预案 / 口径」——
**没有「消息面」段落**，模型没有位置可写，实际输出里消息面基本消失。

→ 修法不是加数据源，而是**加段落 + 规定必须引用 1~3 条带日期的标题**。

### 2. 前期走势与后续研判：**真的缺**
- 第一维「实时行情」只有价格/涨跌/成交量；
- 第二维「技术面」是一句话（空头排列/MACD 死叉(8日)/RSI 中性/支撑压力）；
- 没有任何 5/20/60/120 日涨跌幅、阶段高低点、趋势通道、量能节奏、相对强弱；
- `get_forecast` 是空的，`get_factor_ic_report` 是坏的；
- 结论里的"预案"是模型自由发挥，没有**情景-触发-应对**的结构约束。

## 四、全景诊断重构：按时间轴取数（T-120 → T+1）

```
第一层 前期走势（60~120 日）  ← 新增 get_trend_profile
   · 5/20/60/120 日涨跌幅
   · 阶段高/低点 + 当前位置分位
   · 均线排列（MA5/10/20/60 数值与斜率）
   · 量能节奏（近 20 日量比序列、放量/缩量日）
   · 相对强弱（个股 vs 板块 vs 沪深300，20 日）
────────────────────────────────────
第二层 筹码与资金沉淀（20~120 日）  ← 现有
   · 底仓 CYQ、筹码带、获利盘、集中度
   · 5/20 日主力净额累计（逐笔）
   · 筹码峰迁移（新增：对比 20 日前的峰位）
────────────────────────────────────
第三层 当日盘面（T）  ← 现有
   · 分时画像（位置/VWAP/分段量能/内外盘/五档）
   · 撤单率 + 趋势、逐笔分钟资金、拉升段
────────────────────────────────────
第四层 位置与估值  ← 新增 stock_factor_daily
   · 动量/波动/换手/位置/资金 5 个因子 + 横截面分位
   · PE/PB 分位（数据可用后）
────────────────────────────────────
第五层 消息面  ← 已有，缺段落
   · 研报 3 篇（机构+评级+日期）
   · 公告 15 日（类别标记）
   · 利好/利空各 1~3 条（关键词命中 + 来源）
────────────────────────────────────
第六层 后续研判  ← 新增"情景规则"，不是预测
   · 情景 A（走强）：触发条件 + 目标位 + 依据
   · 情景 B（震荡）：区间上下沿
   · 情景 C（走弱）：失效条件 + 减仓参考位
   · 每个情景必须挂"哪个数据变了就换情景"
   · 明确写「不预测方向，只给条件-反应」
```

### 输出段落（替换现有七段）
`结论 / 前期走势 / 筹码与资金 / 当日盘面 / 位置与因子 / 消息面 / 情景与关键位 / 口径`

## 六、一句话结论

> 全景诊断现在的问题是**时间轴只有一格（今天）**：底部有厚度（筹码/逐笔/盘口都很厚），
> 但往前看不到 60 天怎么走过来的，往后给不出有约束的情景。
> 消息面不是缺数据，是缺段落。
