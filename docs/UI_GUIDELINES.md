## 1. 视觉方向

采用清爽的分析工作台：亮蓝作为唯一主交互色，白色内容面板与轻微冷色页面底形成层次；深色采用墨色页面底和更亮的内容面板。避免大面积紫灰、厚重蓝灰描边、霓虹光晕和装饰渐变。继续使用现有 Radix + Tailwind 基础组件，不再引入另一套组件库。

侧栏与工作区 Tab 的选中态使用淡底色、文字色和字重；禁止选中项左侧彩色竖条、彩色描边和圆角彩色边线。键盘焦点环是可访问性状态，仍需保留。

收起侧栏时所有底部工具必须纵向排列且完全落在 64px 宽度内，能力摘要只显示有完整可访问名称的状态圆点。窄侧栏里的账号、消息浮层向右打开并限制高度，不能向左或屏幕底部越界。账号菜单统一点击展开，避免悬停开启与点击切换相互冲突。

顶部“关闭全部”图标仅在多个页签时显示，执行后只保留常驻首页并返回首页；仅剩首页时隐藏按钮。图标必须有明确名称，沿用批量关闭、卸载与页签持久化流程。

浏览器全屏入口在桌面页签栏右侧、手机顶栏；调用 Fullscreen API 对整个 documentElement 全屏，不改变工作台、会话和页签状态。图标/名称跟随 fullscreenchange，同步 Esc 或浏览器菜单退出的状态；请求失败如实提示并允许重试，不支持原生全屏的浏览器隐藏入口。手机按钮保留 44px 热区，窄屏适当收起时段摘要以避免顶栏越界。

模块边界由空间、底色和分组建立。**内容卡片统一 `border: none`，禁止普通、悬停和选中态描边、装饰 ring、内侧高光及用 inset 阴影模拟边框。** 此项为 2026-10-26 用户最终裁决，取代此前“细弱卡片边线”的约定。共享 Card 所有变体与手写内容容器都遵守同一规则；可以使用轻微外部阴影，不能每层容器重复包卡片。

输入框轮廓、表格内部行分隔、页签栏、浮层边界和键盘焦点各有用途，可使用对应 token；它们不属于卡片装饰描边。输入框、文本域、原生下拉与共享 Select 使用中性浅灰边框，禁止聚焦时的彩色外圈、outline、ring 和发光阴影；焦点只通过同一条边框的中性灰变化体现。复选框、开关、按钮及链接保留原有可访问焦点指示。不得给卡片随意添加 role 或定位来绕过检查。

## 2. Token 与主题

- 颜色唯一来源是 `frontend/src/index.css`。页面底 `background/s0`，主内容 `card/s1`，内部辅助区 `s2`，选中区 `s3`，弹出层 `popover/s4`。组件使用语义 token，不能手写页面级十六进制配色。
- `background/card/popover` 分别别名到 `s0/s1/s4`。修改暗色与舒适模式时只能调整基础层，禁止另起一套同名组件颜色。
- 容器底色不透明，禁止 `bg-card/50`、`bg-background/80`、`bg-s2/40` 等叠色；禁止以 `border-border/30` 随意降低边界。状态色的小面积浅底和模态遮罩允许透明度。
- 主按钮固定使用 `bg-primary text-primary-foreground`，不能硬写白字；暗色主按钮也要满足对比度。
- 涨跌使用 `stock-up/stock-down`；中性指标不能染成涨跌。风险、成功、关注等只在有实际语义时用对应 token。
- 切换主题、密度、舒适模式统一通过 `setAppearance()`；同窗口组件、其他标签页与系统主题变化必须同步。舒适模式仅改变深色外观，不能覆盖浅色。
- 正文与次要文字相对内容底色至少 4.5:1；表单常态边框按用户裁决使用浅灰，聚焦边框使用 `--input-focus` 中性灰并保持至少 3:1。深色卡片与页面底色必须能区分。`token-contrast.test.ts` 负责回归检查。

## 3. 字体、留白、密度

四级主字阶：页面标题 20px，区块标题/重要数值 16px，正文/操作 14px，辅助标签/数据来源 12px。生产界面禁止 10/11px 微字与任意 13px 字阶。公开介绍页可使用专门的大标题阶。

间距以 4px 为基数，卡片常规内边距 16px，模块间距 16–24px；内部数据组间距 8–12px。密度改变留白，不把文字缩到难以阅读。金额、价格和百分比使用等宽数字，保留业务单位及正负号。

## 4. Header、Toolbar 与数据组件

页面优先使用 `src/components/PageHeader.tsx`，包含以下区域，窄屏按自然顺序换行：

1. 一个明确的页面主标题；必要时一句描述。
2. 操作区：主操作最多一个实心按钮，次操作用 outline/ghost；刷新有可访问名称、加载态和禁用态。
3. 元信息区：更新时间、来源、市场状态。不能把交易时段、多个数据源、延迟等全部拼成一行细字。

`StatusChip` 用于短状态或上下文（例如“港股·已收盘”“数据源·需关注”“快照时间”）；不可点击的标签使用 span，可展开详情时外层必须为 button/PopoverTrigger，有展开状态且支持键盘、触摸和 Escape。完整交易时段、当地时间与源明细放在 Popover，不能只靠 hover/title。

价格、成交额、换手率等连续数值用定义列表或对齐网格，不能每个数值都套圆角 Chip。一组互斥视图用分段按钮或 Tabs，表达选中态；筛选条件用可移除 Chip 时需提供明确删除名称。无动作的状态不可伪装成按钮。

区块标题与操作在同一行，长标题允许换行；表格工具栏分离筛选和批量操作。文本超长可截断，但完整信息须有详情入口，不能仅缩字号。

## 5. 布局与浮层

市场全景使用分组式折叠标题（`presentation="group"`）及情绪、主线、温度三张独立卡片，各卡片按内容取高；分组外围不再套整张大卡。其他折叠模块使用 `presentation="panel"`，收起时只挂标题，双列在单项折叠时重新排布，不能保留空白列。

登录后的应用页面统一使用外层工作区提供的左右留白和宽度，根容器使用 `page-container`，不得各页另加 `max-w-* mx-auto px-* py-*` 造成标题起点与内容宽度漂移。公开介绍/条款及卡片内部长文可保留阅读宽度。

每个模块只有一个主要内容面板，内部优先分隔线/留白，避免“卡片套卡片”。图表与表格铺满所属内容区，主图与辅助栏在窄屏堆叠，不能固定右栏导致主图被挤出屏幕。

全局数据使用提示与数据源共用工作区状态行，桌面靠右对齐，窄屏自然换行；禁止另做漂移页脚或悬浮提示条。

个股 AI 分析入口使用 `CopilotCapsule presentation="inline"`，位于工作台工具区；旧保存的拖拽坐标不得影响内联入口。不允许新加常驻悬浮卡片压住数据。全站同一上下文只保留一个 AI 入口，ChatWidget 仍使用现有入口去重机制。

Toast 统一固定在桌面右下角、手机底栏上方；手机保留完整内容宽度，最多同时展示三条，不能挤成顶部窄列遮住导航。

浮层只在用户操作后展开，使用不透明 popover 底和统一 overlay 阴影；不叠加彩色外发光。模态需有标题、关闭名称、焦点管理及 Escape。弹出后不能让底下工具栏穿透可见。固定导航、浮层和移动端安全区必须一起检查。

### 分类页与父子层级

设置、个人中心、管理后台和开发者文档统一采用 `SectionWorkspace`。桌面显示分类导航与当前内容，手机显示有标签的分类选择器。一次只挂载当前分类，不能点击菜单后仍把其他分类堆在正文。导航是父级组织，内容是模块卡片，内部属性使用列表、表格和分隔线，不再重复嵌套整张卡片。

分类选择写入 `section=`，保留所属枢纽的 `tab=` 和其他查询参数。刷新、浏览器前进/后退及分享链接应返回正确分类；非法或未授权分类回到当前用户可见的默认项。分类菜单不得取代后端权限校验。

### 交互容器选择

| 内容 | 组件与边界 |
| --- | --- |
| 同级功能、需要频繁切换 | 共享 Tabs；有选中态、键盘方向键和关联的 tabpanel |
| 独立配置领域或账户领域 | `SectionWorkspace`；每个分类内有明确的模块卡片 |
| 当前任务的主要数据与操作 | 卡片；重要状态及来源、基准日、口径常驻可见 |
| 不常用的高级分配、解释与统计 | details/折叠区；收起不保留正文空白高度，标题说明展开内容 |
| 昵称、密码、服务商等短表单 | 居中 Dialog；明确保存、取消，输入有可访问名称 |
| 最近运行、报告正文、诊断结果、深度配置等长内容 | `SidePanel` 或 `DialogContent placement="right"`；独立滚动，保留来源上下文 |
| 启用/停用、订阅、布尔偏好 | 共享 `Switch`，带具体业务名称；禁止手写 `role="switch"`、轨道或圆点位移 |
| 创建密钥等会立即产生结果的操作 | 先打开明确的表单，再由提交按钮执行；一次性密钥放独立结果弹窗，关闭清除显示值 |

侧边面板沿用 Dialog 的模态语义，不使用可漂移的绝对定位伪弹窗。标题和关闭按钮不能被长内容挤出；Escape 可关闭，焦点返回打开它的按钮。无 `DialogTrigger` 的受控弹窗也必须恢复焦点。需要持续对照的分析工作台可保留原位主从布局，不把所有详情机械地改成浮层。

AI 助手入口必须具备按钮外观、动作说明与进入方向提示；避免只写工具名和参数，看起来像导航标题。

## 6. 可访问性、移动端、状态

- 所有操作可用键盘完成，焦点样式可见。Tabs 支持方向键/Home/End、正确的 tabpanel 关联和焦点移动；图标按钮有名称。
- 常规按钮至少 36–40px；触摸主要目标至少 44px。移动端输入保持 16px，允许浏览器缩放。
- 390px 宽度下页面不得横向溢出；长表格在自身容器滚动。工具栏换行，AI 会话列表使用可展开面板，不强塞桌面侧栏。
- 加载、无数据、错误、更新失败但保留快照分别展示。无数值显示 `--` 并提供“无数据/未取到”说明，禁止填 0 冒充缺失。不得为展示 UI 编造市场数字。
- 来源、基准日、资金口径标签必须保留；不得通过折叠/隐藏把业务口径约束移出用户可见区域。跨市场开闭市继续以后端状态为准。

## 7. 修改与验收

先复用基础组件与语义 token，再添加页面组合；确需新增模式时在此更新用途和边界。不要用各页 CSS 补丁创建新的视觉体系。

提交前执行：

```sh
pnpm --dir frontend typecheck
pnpm --dir frontend lint
pnpm --dir frontend test
pnpm --dir frontend ui:check
pnpm --dir frontend build
git diff --check
```

`ui:check` 检查主应用及两个 UI 包，包含字号、透明容器、表单/结构边界、主题别名、共享 Switch、无描边卡片及原有数据诚实性规则；Node 测试验证规则本身能拒绝错误例子。不得通过新增例外白名单绕过标准。

有视觉或布局变化时，用真实浏览器复核浅色、深色、390px 手机宽度，检查 Header、数据标签、主要操作、加载/错误/空态和浮层遮挡。截图放在忽略的 `output/playwright/`。若本地外部行情不可用，应如实记录验证限制；无数据布局检查不能称为真实行情验收。

变更需同提交更新 CHANGELOG。自动门禁负责客观约束，不能替代用户对整体视觉和操作体验的验收。

模块级布局与交互选择详见 [2026-10-26 模块复查记录](UI_MODULE_REVIEW_20261026.md)。

## 8. AI 助手形象与会话

完整页和右下角迷你窗是同一个会话模块，复用 `AssistantWorkspaceProvider` 的单一实例。切换承载位置不能重建对话、丢草稿或重新提交正在进行的请求；隐藏后暂停可见动画与页面轮询，已提交的回复可继续完成。退出账号时销毁实例，禁止跨账号保留对话状态。

形象只通过 `AssistantAvatar` 渲染。两款本地 Lottie 为 Flow / Foriday，默认第二款 Foriday；选择入口在设置的外观分类与迷你窗的设置按钮。形象偏好按账号保存在本机，同一窗口的菜单、引导、浮窗和气泡即时同步。

设置预览、菜单、悬浮入口、引导区和最后一条 AI 气泡的形象全部保持动画：空闲以 0.55 倍速循环，加载和书写时恢复 1 倍速，切换状态不重置当前帧。形象同时以 4 秒周期在 96%–104% 之间轻柔缩放，使用 transform 避免改变布局。只有最后一条 AI 气泡显示 bot 形象；等待首字时用同一位置的待回复气泡，开始书写后显示正文，此前气泡不再重复头像。减少动态效果、页面隐藏、页签不活动或形象离开视野时，Lottie 与呼吸效果一起暂停。

动画资源随应用托管，不引用外部 CDN；每个播放器使用独立数据副本并在卸载/切换形象时释放实例。播放器控制遵循 [Lottie 官方用法](https://github.com/airbnb/lottie-web/wiki/Usage)。不得为动画放宽 CSP 或额外添加 JavaScript 持续帧循环。

悬浮形象桌面 96px、手机 80px；左侧小气泡随机显示预设技术分析引导，20 秒后更换且不连续重复，工作中显示进度提示，不做读屏轮播；点击形象或气泡均打开助手。加载时不显示旧图标或静态占位，播放器准备好后再显示。桌面迷你窗停靠右下，手机打开即覆盖完整可视区并位于应用顶栏和底栏上方，仅在窗口内部保留安全区；跟随 visualViewport 的高度和偏移适配键盘与旋转，正文独立滚动。手机不显示冗余的全屏切换按钮，桌面保留全屏/浮窗切换；展开到完整页保持同一会话。

打开、重新打开和切换全屏均不得自动聚焦输入框，避免手机立即弹出键盘；输入由用户主动点击。输入框独占整行，手机默认一行、回车换行、点击发送按钮提交；文字增加时自动增高，达到高度上限后仅在输入框内部滚动。手机字号至少 16px，附件、后台与发送操作另起工具行，手机点击热区至少 44px；桌面保留 Enter 发送、Shift+Enter 换行。关闭窗口恢复入口焦点，回复完成不能抢走用户在其他区域的输入焦点。

引导气泡必须提供独立关闭按钮，不得在打开助手的按钮内嵌套关闭按钮。关闭偏好按账号保存在本机，刷新、切页、重新打开迷你窗和忙碌状态变化均不再显示文字气泡，并停止文案轮换；动画入口继续保留，关闭后焦点返回入口。浏览器拒绝持久化时仍在当前窗口记住关闭状态。


## 9. 系统状态与连接图

“系统自检”入口直接进入 `/system/status` 完整页面，不再打开自检弹窗。系统页的状态页签复用 `SystemStatusPanel`，通过“详细数据”进入完整页，仅管理员查看运维状态。状态行左侧的 `SystemStatusIndicator` 显示核心状态，点击小面板查看摘要并前往主页面。采用无边框模块节点、依赖连线、状态 Chip 与点击后的右侧详情；手机在图内横向滚动，不能撑宽页面。详情显示检测依据并提供配置入口，禁止只依赖鼠标悬停。

打开先渲染完整模块布局，按账号读取本会话的脱敏缓存并显示记录时间；首次无缓存也展示 9 个未知状态节点。刷新时叠加加载提示、节点更新标记与实际完成进度，不能清空为单独的 loading。只读 `/api/health/system/stream` 通过 SSE 逐模块覆盖新结果，未返回项保留旧值且不流动，完整更新才替换缓存时间。图标与完整页共用 `SystemStatusProvider` 的一个流，前台每 30 秒更新，窗口隐藏暂停；隐藏页面只暂停自身连线动画。基础健康收集不调用 AI 或发送通知。保留原公开 `/api/health` 的内外网裁剪；新快照不含连接串、凭据或原始系统错误。失败保留已取得的数据并停止流动；缺失项显示未检测，不能伪造为正常或未配置。

流动表示最近检测连通，不代表真实请求流量。未配置、未知、待命、异常连接不流动；历史数据源统计不等同当前连接，通知仅校验配置不等同投递成功。调度器 standby 必须说明当前进程待命且主实例未验证。尊重减少动态效果，隐藏页签停止流动。

主动检测必须由用户点击，使用 POST，避免 GET 缓存和自动重试重复调用模型或发通知；并发上限 4。AI 检测的用量与通知真实发送开关必须可见，通知默认不发送。只探测当前账号和共享通知渠道，不测试他人渠道；CLI 保留原有全局自检用法。主动探测结果最多点亮线路 60 秒，长时间未验证回到未知状态。

## 10. 行情标的与切换

行情导航经 `/quotes` 读取当前账号持仓与关注列表，优先恢复仍在列表内的上次选择，否则先持仓、再关注；两者都没有才显示默认指数，并明确说明默认原因。接口失败必须显示读取失败和重试，不能当作没有股票。

工作台常驻可搜索的持仓/关注切换入口，按市场与代码去重，提供股票列表管理入口。选择时保留 CN/HK/US 市场，账号偏好隔离；同代码不同市场的页签不能合并。切换类型必须指向有效标的，不能只改 type 后把原股票代码当作指数/板块。

个股与指数可能同代码，日 K 与分时请求必须显式传递 instrument，后端取数和缓存都纳入类型。页面名称、行情、图表和持仓成本线必须属于同一个市场和标的；不可用时显示真实空态/错误，不用另一个标的数据兜底。
