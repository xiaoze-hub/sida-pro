# TQ（通达信客户端）切换面审计

> **① 基线标识**: commit `1ac251a`（main）/ `VERSION` = `v0.13.9`（生产同版本，健康）
> **② 审计对象完整路径**:
> - `packages/marketdata/src/marketdata/registry.py`（能力→vendor 注册表）
> - `packages/marketdata/src/marketdata/vendors/*.py`（33 个数据源实现，含 `tq.py` 1029 行）
> - `src/bootstrap/datasources.py`（`DATA_SOURCE_SEEDS` 43 条种子 + `_seed_providers_by_type`）
> - `src/collectors/*.py`（20 个）、`src/core/*.py`、`src/web/api/*.py` 中的外部源调用点
> **③ 覆盖范围**: 审了**数据获取层**（vendor 注册表 16 个能力 / 种子 43 条 / 全仓外部 URL 与 TQ 方法调用点）；
> **没审**: `frontend/` 展示层、`wudao_mcp_client`/`ftshare`/智兔 的商业条款与配额、`tdx.py`(通达信云 MCP) 与 TQ 的重叠关系。
> **结论性质**: 本文件是**盘点与建议**，不含已实施的切换；每条建议的落地都需单独发版 + 验证。

## 〇、一句话结论

TQ 的**封装层已完整**（`tq.py` 有 30+ 个 wrapper，覆盖 GP/SC/BK 序列、快照、财务、公式、板块、交易日历、订阅推送），
但**业务层只接了 9 处、registry 只注册了 3 个能力**（`quote`/`kline`/`more_info`）。
剩余工作不是"能不能拿到数据"，而是**按能力补接线 + 补 registry 注册 + 补 seed 行**。

## 三、TQ **无等价**（保持外部源，不要试图切换）

- **公告 / 事件 / 新闻**：`events` / `news` / `flash_news` → 东财、新浪、财联社、同花顺。
  TQ 无信息披露类方法（盲探 25 个同义词全部 `-32601`）。
- **互动易** `cninfo_irm`、**海外**（alphavantage / twelvedata / yfinance）、**F10 语义字段**（席位名 / 机构名 / 营业部名，TQ 只给金额）。
- **北向**：已停披露，仅持股量（GP06/GP18）可用，净买入类字段全 0。
- **竞价 / 逐笔明细**：TQ 无 tick 明细接口。明盘走 thsdk、暗盘走腾讯逐笔（zero-cost 口径，见 `a-share-main-force-intent`）。

## 四、切之前的硬约束（漏掉会静默出错，不是崩溃）

1. **口径红线（AGENTS.md 硬约束）**：资金类返回值必须带 `caliber` + `direction_semantics`；
   **主力意图/吸筹派发只准走 `get_main_intent`（腾讯逐笔）**，`get_capital_flow`（东财按单金额四档）禁止用于方向判定；
   TQ 口径对应 `get_decision_pioneer`（L2 主力净流入）。
   ⇒ 把 `capital_flow` 主源换成 TQ **等于改变口径**（公式成品 vs 按单金额归类），
   必须带标签、且出口经 `require_directional()` 校验 —— **建议先只做备源，不动主源**。
2. **单位**：GP/SC 系列金额一律**万元**（GP02 需 ×1e4 对齐东财的元）。不换算会**错 10000 倍且不报错**。
3. **TQ 是单点且脆弱**：客户端在 Windows，靠 portproxy（`172.27.16.1:17709`，重启后会丢需重加）；
   **单次请求标的数 ≤ 50**（超了打挂客户端，实测只能整机重启）；突发连接会 reset（间隔 0.7s + 重试 3 次）。
   ⇒ 任何一处的批量取数都必须分片，`_TQ_CHUNK = 50` 是硬线。
4. **时效**：L2 成品字段（`Zjl`/`BCancel` 等）**盘后全 0**，须盘中取值；`SC1`/`SC15` 末日可能是 T-1。
5. **降级不缓存**：`lhb_pending` 类的降级响应不得入缓存（v0.13.9 实踩：空值被缓存 24h 会把新能力对用户遮住一整天）。

## 五、建议顺序（按"风险低 / 价值高"排）

1. `shareholders` + `dividend` 加 TQ **备源** → 直接省智兔付费调用，且不改主源（零口径争议）。
2. `board_capital_flow` 加 TQ 备源 → 解同花顺单点。
3. `margin` 加 TQ 源。
4. registry 层给 `dragon_tiger` 注册 tq → 与端点已有的融合路径保持一致。
5. `capital_flow` 加 TQ **备源**（**不要先动主源**，先解决口径标签 + 方向判定隔离）。
6. 涨跌停快照 `zdt_snapshot` 作为东财 `push2ex` 的备源（TQ 独有：封单量、首封时间、炸板次数）。
7. `market_capital_flow` 端点改读已落库的 SC 序列（家数已由 TQ 覆盖，资金类字段需先定口径）。

每项落地 = 一个独立分支 + 该能力的**新旧源对照验证**（旧源为真、新源转绿才算过）+ 一处生产实测。
