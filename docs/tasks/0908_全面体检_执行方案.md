## 〇、全局规则（所有任务必须遵守，冲突时以 AGENTS.md 为准）

### 红线（违反即打回）
1. **单位口径**：金额=元，成交量=股；`vol × price == amt` 必须精确匹配。
2. **禁止编造**：数据缺失必须显式标注"无数据"，禁止推测/编造默认值；兜底逻辑必须打日志。
3. **多用户隔离**：4 账号并存（owner + 3 member），任何接口/数据改动必须考虑 user_id 隔离，回归必须多账号验证。
4. **主力意图**只走 `get_main_intent`（逐笔口径），禁用 `get_capital_flow` 判主力意图。
5. **缓存**一律走 `src/web/cache/biz_cache.py`，禁止业务代码裸连 Redis（基础设施用途如选主/WS seq 除外，但必须连接复用）。
6. **K线读取**走 PG hypertable（`get_klines()`）。
7. 通达信客户端稳定性是红线，任何改动不能导致假死。

### 工作流
- 分支：`fix/<事>-0908` 或 `feat/<事>-0908`，从 main 拉；合并前 `git log origin/main..HEAD` 确认只含自己的活。
- Commit 格式：`<type>: <subject>`，type ∈ {fix, feature, update, doc}，subject 中文。
- **每个 commit 必须同 commit 更新 CHANGELOG.md**（写清改了哪个文件、为什么改、测了什么，末尾缀 `[commit <short-hash>]`）。禁止代码与 changelog 分两个 commit。
- 修复必须回**实测证据**（测试输出/命令结果），不许只写"已修好"。

### 通用验证命令
```bash
python -m pytest tests/ -v                        # 后端全量（默认不发通知）
cd frontend && pnpm typecheck && pnpm build       # 前端门禁
node scripts/check_ui_rules.mjs                   # UI 门禁（输出 UI-RULES OK）
```
新增测试文件命名 `tests/test_<模块>.py`，每个测试函数第一行中文 docstring；mock 掉网络与 AI 调用，禁联网。
