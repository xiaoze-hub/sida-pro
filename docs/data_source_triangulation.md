## 三、算法设计：暗盘v6三源融合

### v6 = v4聚类(不变) + 三处升级

```
逐笔层(实时):
  腾讯逐笔 ──→ v4聚类 ──→ 暗盘净额T
  thsdk L2逐笔 ─→ v4聚类 ──→ 暗盘净额H   (方向精度升级)
  差异 |T-H| 大 → 标记方向分歧，不轻信

明盘层(交叉验证):
  腾讯四档主力净 + thsdk big_order_flow + TQ Zjl_HB
  三源同向 → 采信; 有分歧 → 标记，不删数

涨停股专项(破局点):
  thsdk被动分离: 只算主动(|方向|=1)拆单簇，剔除被动散户潮(|方向|=2)
  假设: 涨停板被动卖出潮是散户获利了结，剔除后方向回正
  验证: 5只回测(龙版/我爱我家/亚盛方向回正即成立)

新维度(撤单率):
  TQ BCancel/SCancel → 撤单率异常=假挂单/诱多信号
  与暗盘净额同向 → 加强; 背离 → 预警

趋势层(选股):
  腾讯5日主力净流入 + thsdk当日DDE → 持续流入选股
  (呼应"暗盘持续流入=主力吸筹"铁律)
```
