## 一、定位与形态

- **是什么**: 自托管 **A 股行情终端 + AI 盯盘/决策助手**（Web, 大屏优先）。不是行情网站、不是数据堆砌看板 —— 核心是"看图决策"。
- **部署形态**: 单容器 `panwatch`(FastAPI + 前端静态资源同镜像), 国内小主机 WSL + nginx 反代, 域名 `www.sida.hengsheng-elec.com`; 另有独立 `forecast_server.py`(8010, 预测引擎, 当前**未启动**)。
- **商业形态**: API Key + Skill Gateway（外部 LLM/Agent 可调用）+ 四档权限（guest/member/pro/owner）+ 可运行时调整的「免费档」。

## 三、数据源矩阵

| 源 | 用途 | 现状 |
|---|---|---|
| **TQ（通达信 TQ 私有 SDK）** | 明盘 L2 主力净额（DDE 官方口径）、撤单率、扩展字段 | 生产主链路（`tq.py`/`registry.py` 走私有 wheel 打进镜像） |
| **thsdk（同花顺 SDK）** | 竞价快照、L2 逐笔、机构/撤单 | 已接；正式账户 `THS_USERNAME` 已配；**未切主链路**（遗留 A2） |
| **腾讯（逐笔 + 行情）** | 暗盘（v6 稳定版）、分时、内盘外盘 | 生产主力（暗盘定稿口径） |
| **东财** | 四档资金流、板块、涨停池、龙虎榜、公告 | 生产主力（榜单/复盘） |
| **新浪** | K 线兜底 | 兜底源 |
| **.tck / .img**（通达信本地文件） | 超盘回放、盘口还原 | 引擎与解析都在，**生产无消费方**（遗留 A2） |

三源"主力资金"口径**本来就不同**（定义/覆盖/时间窗/基准日）→ 已做「口径对照」页消歧（`/caliber-compare`）。

## 四、能力面

- **K 线六图层**（设计稿 §5 核心卖点）: GS 买卖点 / 资金柱 / L4 事件图标 / 支撑压力 / 持仓成本线 / 活跃度副图 —— 已接线到工作台与分析页，图层按需自取 `summary`。
- **§10.2 交互**: 双击还原、滚轮缩放、`?period=` URL、十字光标联动（明盘/暗盘/事件同刻读数）、区间统计卡。
- **数智决策三指标**: 机构活跃度（生命线 1.56/强势 3/大牛 6）+ GS 趋势（G 买/S 卖）+ L2 主力净流入（TQ 口径）→ 共振状态机。**2026-09-18 起 pro 档**。
- **集合竞价池**（9:25 竞价数据 + 竞价异动池）：**2026-09-18 起 pro 档**。
- **影子账户**：交割单 → 行为画像 + 影子规则 + 归因；**成交明细可标回 K 线**（§6.2）。
- **AI 对话**：28 个工具（行情/资金/意图/竞价/复盘/预测/新闻/基本面/自选/画像…）；口径红线：主力意图走逐笔、东财四档只作参考。
- **通知**：10+ 渠道（企业微信/Server酱/PushPlus/钉钉/飞书/Discord/Telegram/Bark/Pushover…），按用户隔离。
- **权限**：四档 + **免 费档运行时可调**（试用功能/日限/skill 档位覆盖，30s 热生效）。

## 五、交付链路

```
feat/fix 分支 → 门禁(gates: bash -n / deploy stub / gitleaks / pytest+覆盖率 / 前端tsc+eslint+vitest+ui-rules)
  → merge --no-ff → main → tag vX.Y.Z
     ├─ build-push-acr      (linux/amd64 → ACR → 小主机 docker pull → 重建容器)   [生产通道]
     ├─ build-and-push-image(ghcr linux/amd64+arm64 → GitHub 镜像)
     ├─ build-push-acr-forecast (8010 预测引擎镜像)
     └─ release             (GitHub Release)
```

- 2026-09-18 之前: 自 v0.9.0 起**四线全红**、Release 停在 v0.4.78（发版断供）。
- 2026-09-18 修复后: v0.10.8 **四线全绿**，v0.10.9 已上线，v0.10.10/11 滚动中。
- 部署纪律: `pull` 先行失败即退出 → 旧容器 `stop+rename` 保留回滚 → 健康后三重验证（`docker inspect` 镜像名 / `cat /app/VERSION` / `/api/health`)。
