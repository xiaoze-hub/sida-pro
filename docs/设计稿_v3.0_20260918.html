数智分析 Pro · 设计稿 v3.0

2026-09-18 基线 commit 21de536 / 生产 v0.10.24 替代 v2.1（功能面已达成，本稿转向「终端度与可测质量」）
一句话定位：SIDA Pro 有两条产品线、一套账号体系—— 公开面（官网落地页 → 邮箱注册自动签 Key → 开发者文档与在线调试台）面向"要接 API 的人"， 终端（34 页行情/机会/持仓）面向"自己盯盘决策的人"。两条线的设计语言刻意相反（见 §三）。
终端侧所有设计决策以三条铁律裁决：
① K 线是主角（个股/指数页 K 线宽度 ≥ 80% 屏宽，无卡片包裹）；
② 不堆数据（只留"决策需要"的字段；缺数据不占位）；
③ 诚实口径（涨红跌绿、单位自动亿/万、缺失显 -- 且与 0 视觉可分、资金数字必带口径徽标）。

一、为什么现在出 v3.0：v2.1 的账已经结清

v2.1（2026-09）定义的是功能超集：21 页面全部保留、K 线六图层、§10.2 交互、§11 通知协议、 §12 数据源兜底、§13 持仓跳路由。截至 v0.10.24 这些功能面已 100% 落地，且刚完成三件收尾： InteractiveKline 退役（删 1280 行，全仓只剩一个图表内核 + 一个分时部件）、口径对照页与口径档案（漂移留痕）、 决策日志（信号 → T+1/3/5 结果的账）。

所以 v3.0 不再列功能，而是回答一个更硬的问题： 「东西都有了，为什么看起来还不像专业终端？」——并把答案变成可测的数字。

诊断一：K 线主角度不够 —— 这是铁律唯一被违反的地方

个股页 K 线只占 55.2% 屏宽，指数页 76.7%。也就是说：我们最核心的页面，主角占了不到六成屏。 v2.1 的「核心三栏布局」是罪魁——左栏自选 + 中栏 K 线 + 右栏决策信息，两栏固定宽度把 K 线挤成夹心。

诊断二：字阶碎片化 —— 首页"乱"的可测根因

首页同时使用 11 种字号（9/10/11/12/13/14/15/17/20/22/30），其中 9、15、17、22、30 都在标准集之外。 字号种类每多一种，视觉层级就多碎一层；首页"乱"不是配色问题，是层级问题。

诊断三：信息堆砌 —— 两个极端同时存在

  • 题材页：526 条 1px 线 + 密度 9680 字/千像素（表格塞到几乎没有呼吸感）；
  • 个股页：73 处 -- —— 诚实标注是对的，但一屏 73 个"没有数据"是噪声： 缺数据的字段不该占位，应该聚合成一行「本页缺 N 项（点击展开）」。

待查（本稿不妄下结论）

持仓页出现 4 处 0.00 形式数字，需人工逐条确认是真实 0还是用 0 冒充无数据 （后者触犯诚实口径红线）。列入 P0 核查项，不默认它是 bug。

3.2 公开面设计规范（新增）

  • 字阶上限 7 档：12 / 13 / 16 / 20 / 28 / 36 / 48。营销页允许比终端宽（终端 6 档、最大 20px）， 但要有上限 —— 落地页现状 13 种，收口到 ≤7；
  • 落地页固定 6 段：① 一句话价值（给谁用 · 解决什么）② 三能力卡 ③ 证据（数据/示例/真实截图） ④ 调用示例（可复制）⑤ 档位与差异 ⑥ CTA。现状缺 ①（首屏只有 hero + 两个按钮，没回答"给谁用/解决什么"）；
  • 文档页三栏：左目录 sticky（跳任一章节）／中正文／右「在线调试台」常驻。 事实更正（2026-09-18）：实测 `DevPageLayout` 已有 sticky 左目录（8 章锚点，`md:sticky`）—— 上一版把"页高 7281px"读成了"单栏无目录"，属于用度量推断功能缺失。 真实缺口只剩两条：① 调试台非常驻（是正文里的一个 Section，不是随读随试的右栏）； ② 没有档位/定价对比（free/pro 只散在限流表里）。
  • 转化路径 ≤2 步：落地页 → 免费注册 → 立即拿到 Key（现状已满足，视作回归线：任何改版不得让它变长）；
  • 两条线口径必须一致：文档示例里的数字与终端里同一指标不能是两个值——口径徽标（tick / eastmoney4 / ths）同样适用于文档示例；
  • 公开面同样禁外部 CDN（唯一匹配是一次误报：命中的是 index.html 里"为什么去掉 CDN"的注释，已查证非依赖）， 动效只用 CSS，不引库。

3.3 数字排版规则（终端的脸面）

  • 等宽对齐：所有数字列 font-variant-numeric: tabular-nums + 右对齐，小数点必须列对齐；
  • 单位自动：|v| ≥ 1e8 → 亿，否则 万；单位后缀用 10px 灰字，不参与对齐；
  • 0 与无数据必须可分：真实 0 → 0.00；无数据 → --（灰）；禁止用 0 表示"没有数据"；
  • 口径徽标：所有资金类数字（净流入/净额/净占比）右侧跟 10px 徽标（tick/eastmoney4/ths）， 悬停显示口径差异一句解释；两口径冲突时并列不合并，且优先采信逐笔。

3.4 密度与间距

  • 基准行高 24px（表格）/ 28px（列表）；区块间距 12 / 18 / 24 三档，不出现第四档；
  • 密度目标区间：1500~3500 字/千像素。低于 1500 = 空白浪费（首屏看不到结论）；高于 4000 = 堆砌（题材页现状 9680）；
  • 一屏（900px 视口）必须能看到结论 + 证据 + 动作提示三件事，超出的信息按需下钻。

  • 左：导航/对象列表（可折叠）；中：图或结论；右：上下文（口径、来源、时间、动作提示）；

  • 单列布局，最大宽 720px，字段间距 18px；危险操作必须二次确认 + 明确后果文案；
  • 不出现"仪表盘式"指标卡堆叠（设置页不是数据页）。
