# 个股工作台 v2（行情 + 盘口 + 旧详情 三合一）设计

> 状态：待实现 · 2026-09-13 · 作者：AI（老板复核后转实现计划）

**目标**：把「行情页」「盘口页」「旧个股详情（9 tab 模态，已在 v0.5.93 删除）」三处内容**合并进个股工作台 `/stocks/:symbol`**，补齐旧详情里被删掉的内容（盘中监测建议、技术指标买卖建议、行情快照、扩展指标、暗盘资金、公告/新闻/简介/报告/深度/龙虎榜…），并**去重**（同一数据点只出现一处）。工作台成为个股的**唯一入口**。

**非目标**：
- 不改后端业务口径；只做前端合并 + 复用既有 API（`insightApi` 与后端 `insights.py/darkflow.py` 均完好）。
- 不重写旧详情的业务逻辑：从 git `b49263c` **恢复 `insight/` 组件复用**，不重新实现。
- 不引入 mock 数据。

---

## 全局约束（项目红线）

1. **真数据**：所有读数走真实接口；源不可用 → `None`/`--` + note，**绝不编**（KI-050「状态与数字同一口径」同样适用于工作台每个读数）。
2. **Key 不进代码/日志/commit**；只走 Tailscale/内网。
3. **每个 commit 同改 `CHANGELOG.md`**；提交只加显式路径（禁 `git add -A`）。
4. 门禁：后端 `PYTHONUTF8=1 python -m pytest -q -p no:warnings -m "not network"`（已知 7 项 KI-055 baseline 失败为正常）；前端 `npx tsc -b` / `npx eslint .` / `node ../scripts/check_ui_rules.mjs` / `npx vitest run`。
5. **纯前端改动用静态面部署**（`docker cp frontend/dist/. → /app/static/` + VERSION + chown，**无重启**，勿杀容器内 nohup 回填）。
6. `packages/biz-ui` 不 import `src/web`；前端 R6 禁 `.toFixed(`（用 `lib/format` 的 safe*）。
7. 交易时段默认不动生产（盘中改动须老板当场点头）。

| 路由 | 变更后 | 说明 |
|---|---|---|
| `/stocks/:symbol` | **三类型唯一详情页**（`?type=stock\|index\|board`，默认 `stock`；`?tab=` 深链下部标签） | 本设计主体 |

### 1.3 指数/板块（`type=index|board`）

- **同一路由内切**：类型切换只改 `?type=`，不跳页（老板选"工作台内切类型"）。
- 顶部带 1（名称/价格/类型切换）**共享同一组件**，三类型视觉一致。
- 指数/板块**正文复用既有成熟页**：把 `IndexDetailPage`(244行) / `BoardDetailPage`(307行) 的正文**抽成组件** `IndexBody` / `BoardBody`（数据与渲染原样搬移），工作台在 `type=index|board` 时渲染对应 Body；原 `/index/:symbol`、`/boards/:code` **退为 redirect** 到工作台（§1.1）。**不重写业务逻辑，只搬位置。**

- 抽取前的页面骨架（返回按钮/刷新/头部）并入共享 `HeaderBand`，避免重复。
