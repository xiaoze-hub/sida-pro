## 三、生产环境坑（本轮实测）

1. **`WEB_WORKERS=2` + 慢启动** → uvicorn supervisor 杀 worker，`Child process died` 循环，health 10s 超时。  
   **本机临时改 `WEB_WORKERS=1` 后 healthy**。根治：降低启动 import 面 / 提高 health 超时 / 等完整启动再挂 health。
2. **JWT_SECRET 24 字节** — 启动告警已生效（KI-030）。
3. **`/hermes` 不可挂载** — 权限拒绝，回退 `/app/data/cron/output`（警告可接受）。
