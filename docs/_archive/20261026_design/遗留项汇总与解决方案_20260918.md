## A. 需要你拍板才能动的（3 项）

### A1 数智决策三指标 / 集合竞价池 · 免费档默认值要不要再放开

- **现状**: 已按你的口径收成 pro 专属; member 默认只剩 机会/L2资金/暗盘资金 各 3 次/天。
- **风险**: 老 member(黄磊/娟姐/demo)打开工作台会发现三指标区、竞价 Tab **不再出数**(API 403 + 升级提示)。
  这是"预期内"的行为变化, 但**是行为变化**。
- **解决方案**: 已给可调开关 —— 系统设置 →「免费档」勾上 `数智决策`/`集合竞价池` 即恢复试用(日限可调), **30s 热生效, 不用发版**。
  - 建议: 先保持 pro 专属 1~2 天看反馈; 若要过渡, 勾上试用 + 日限 3, 观察一周再收。
- **谁做**: 你(在面板上点) / 我(给你一份"要不要放开"的数据: 近 7 天这两个功能的实际调用者与次数)。
- **依赖**: 无。

### A2 §3 数据源: thsdk 灰度未切主链路 / `.img` 生产未落地

- **现状**: `thsdk` 已接(三指标里 L2主力净流入走 TQ 口径), 但**明盘主链路**仍以腾讯/东财为主;
  `.img`(通达信本地盘口文件)解析引擎与 `orderbook_engine` 都在, **生产链路没有消费方**。
- **风险**: 口径双轨 —— 同一只票"L2主力净流入"与"东财四档资金流"数字不同(设计如此, 但用户容易混);
  `.img` 不落地 = 盘中逐笔/盘口这块能力闲置。
- **解决方案**:
  1. 先做**口径对照页**(半天): 同一票同一时刻并列三种口径(thsdk L2 真值 / 腾讯逐笔 / 东财四档), 标注单位与差异原因 —— 不改主链路, 只把差异显式化。
  2. 灰度切主链路(需你在盘中在场): 按 `AUI/建议` 顺序 —— ① 明盘主力净额切 thsdk(DDE 官方口径) ② 保留腾讯作交叉校验 ③ 出对照日报 3 天无异常再撤旧源。
  3. `.img`: 先在**盘后回放**里接(不碰实时), 用历史 `.tck/.img` 回放验证解析 → 再评估上实时。
- **谁做**: 我(1、3)+ 你(2 的切换时机)。**建议先做 1**, 因为它零风险且立刻回答"两套数字为什么不一样"。
- **依赖**: 小主机 thsdk 正式账户(`THS_USERNAME` 已配); 盘中观察窗口。

### A3 §10.1 双 K 线引擎并存（自研 InteractiveKline vs Lightweight Charts 封装）

- **现状**: `InteractiveKline`(1268 行, 主力意图/涨停标注/筹码)与 `KlineChart`(996 行, 六图层/事件图标/区间统计)并存;
  两个组件**能力各有偏**: 前者以"主力意图/筹码"见长, 后者以"设计稿六图层 + 交互规范"见长。
- **风险**: 维护双份 marker/区间过滤/主题逻辑; 同一个页面(工作台/分析页)可能两种图观感不一致。
- **解决方案**(分三步, 每步都可停):
  1. **抽公共层**(1~2 天): 把两者重复的 marker 分组聚合、`filterMarkersInBarsRange`、主题取色、区间统计抽到 `biz-ui/src/lib/*` 纯函数(已经有 `range-stats.ts` / `chart-markers.ts` 打底)。
  2. **能力对齐**(2~3 天): 把 `InteractiveKline` 独有的主力意图/筹码叠加迁到 `KlineChart` 的图层体系(新增 `mainIntent` 图层的开关与配色)。
  3. **退役**(1 天): 全页面切 `KlineChart`, 删 `InteractiveKline` + 相关测试; 用截图对比保证观感不退化。
- **谁做**: 我。**建议**: 先做 1(纯重构、零行为变化、收益立刻), 2/3 等 A2 定完再排 —— 因为筹码/意图叠加依赖口径。
- **依赖**: A2 的口径结论(第 2 步起)。
