## 三、架构关键点

### thsdk_l2.py 封装已就位 (1103 行)

22 个类方法 + 27 个便捷函数 + 2 个分析器 = ~50 能力。本版激活了:
- `compute_main_flow` (主力拆分)
- `get_auction_anomaly` (竞价异动池)
- `get_comprehensive_snapshot` (一拉全量)
- `thsdk_alert.run()` (三大算法)
- `get_ths_industry / get_ths_concept` (板块列表)
- `get_block_market / get_block_constituents` (板块详情)

### 主力意图双源对比

thsdk L2 大单 vs 腾讯逐笔实时,计算:
- `consistency` = 1 - |t-h| / max(|t|, |h|, 1) → 0-100
- `delta_pct` = 100 - consistency
- 异常容错:thsdk 失败 → note="thsdk 数据暂不可用"

### cron 复用

- 08:30 板块同步 → 复用 `report_scheduler.scheduler` (AsyncIOScheduler)
- 09:25 竞价异动 → 同上
- 禁止新建调度器(已记入AGENTS.md)

### 数据源 DB 修复(持久化)

```sql
UPDATE data_sources SET enabled=0 WHERE type='kline' AND provider IN ('eastmoney','stooq');
UPDATE data_sources SET priority=3 WHERE type='kline' AND provider='ths';
```

**教训**: docker cp 热修源码 ≠ DB 修复。下次部署前必须复检 DB 状态。

1. **测试机 → 生产部署** (按 AGENTS.md 流程):
