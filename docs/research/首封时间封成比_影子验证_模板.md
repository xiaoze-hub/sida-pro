## 0. 一句话

**影子运行**:每日盘后对当日涨停股打 S/A/B/C 强度标签,只落 `limit_strength_shadow` 一张只读表,
**不改任何现有信号/决策**;徽章只读展示,悬停标注「影子运行·仅统计参考」。因子是否有效,靠
**20 个交易日后的分桶对比**回填判定,不提前下结论。

信号是**证据非建议**;全流程禁「建议买入」类措辞。

## 1. 因子口径

| 维度 | 取值 | 来源 |
|---|---|---|
| 首封时间 | 桶:竞价(≤09:30)/早盘(≤10:00)/盘中(≤14:30)/尾盘 | TQ `get_zdt_data.FirstTimeZT`(GP24 首回涨停时间为备源) |
| 封成比 | 封单额 ÷ 流通市值;档 C(<1%)/B(<3%)/A(<5%)/S(≥5%) | 封单额=`get_more_info.limit_up_amount`(元), 流通市值=`Ltsz` |
| 炸板次数 | 参考 + 降档:OpenTimesZT ≥1 → 标签降一档 | TQ `get_zdt_data.OpenTimesZT` |

标签矩阵(降档前):

| 封成比 ↓ / 首封 → | 竞价 | 早盘 | 盘中 | 尾盘 |
|---|---|---|---|---|
| S(≥5%) | S | S | A | B |
| A(3–5%) | S | A | A | B |
| B(1–3%) | A | B | B | C |
| C(<1%) | B | C | C | C |

缺数据(首封时间或封成比任一缺)→ `status=no_data`、`label=null`,**不出标签、不编造**。

阈值全部在 `src/core/thresholds.py`(键 `first_seal_*` / `seal_ratio_*` / `blow_downgrade_open_times`),
env 覆盖,禁硬编码。

## 2. 分桶对比口径(判定是否有效)

**目标**:验证「高强桶(S/A)」的 T+1 / T+3 收益命中率是否显著优于「低强桶(C)」。

- **样本单位**:单个 (交易日, 涨停股) 对。
- **命中定义**(择一,须在结论里锁定并写死):
  - 口径 H1(收盘命中):T+1 收盘涨跌幅 > 0 记命中;
  - 口径 H2(打板命中):T+1 开盘价 < T 日涨停价 且 T+1 最高价 ≥ T+1 涨停价(有可打板点且延续)记命中。
- **分组**:按强度标签 S / A / B / C + no_data 分组。
- **统计量**:每组命中率、样本数、平均 T+1/T+3 收益;差值 S/A 组 − C 组。
- **样本门槛**:**每组样本 ≥ 30 才出结论**;不足则该组标「样本不足, 不出结论」。
- **观察窗口**:**20 个交易日**内只累积、不判定;第 20 个交易日后回填判定。
- **显著性提示**:给 Wilson 95% 置信区间(命中率是比例, 别用正态近似糊弄小样本)。

|---|---|---|---|---|---|
| S | | | | | 样本<30 → 不出结论 |
| A | | | | | |
| B | | | | | |
| C | | | | | |
| no_data | | | | | |

**判定规则(先写死,防事后调参)**:
1. S+A 组命中率 **显著高于** C 组(95% CI 不重叠)→ 因子方向成立,考虑把标签纳入信号;
2. 无显著差异 → 因子**无效或口径需改**,记入否决;
3. 结论**一律不得**表述为「建议买入」,只写「统计上 X 组优于 Y 组」。

## 4. 历史回测脚本(能跑多少跑多少,缺口显式)

`scripts/limit_strength_backtest.py`:
- 只读 `limit_up_events`(已落库涨停事件)+ 历史日K(`get_klines`)推 T+1/T+3 收益;
- 首封时间/封单额历史值**多数未落库** → 脚本对缺首封时间的样本显式计为 `gap`(不进桶),
  **不臆造首封时间**;
- 输出:每桶样本数、命中率、缺口计数与占比;缺口大时明说「历史首封数据不足, 结论推迟到
  影子运行满 20 交易日后」。
- 铁律:只读,不写任何表;`--write` 之外无副作用。
