# 通达信接口可用数据清单（2026-09-13 研究）

> 来源: 老板提供的《TdxQuant接口说明文档》(全文抽取 `~/tdx_doc_text.txt`, 231 页)。
> 目的: 盘点通达信还哪些数据可供 SIDA 使用, 分组+优先级, 供老板拍板。
> 约束: 我们定位**分析/决策支持, 不做下单交易** → 交易/下单/预警推送类不接。

## 已在用
- `get_market_data`(日/分钟K)、`get_market_snapshot`(快照+五档+开高低)、`get_more_info`(L2: 涨停价/封单/逐笔/主力净流入/连板)、
  `get_pricevol`(批量价量)、`get_stock_list`/`get_sector_list`/`get_stock_list_in_sector`(板块/成分)、
  `formula_process_mul_zb`(AMO/SUPAMO 成交额/主力额)。

## 未用但可用（按价值分组）

### P1 高价值·低工作量（建议先做）
- `get_relation` / `get_block_name`: **个股→所属板块反查**。→ 梯队每行「题材分布chips」+ 工作台「题材/板块」卡(现缺)。
- `get_trading_dates`: 交易日历。→ 与自建日历交叉校验(节假日/调休), 消除回填/连板推算的日历误差。
- `get_divid_factors`: 分红送配/复权因子。→ 交叉校验 qfq 复权(复权污染是历史坑 KI-011)。

### P2 中价值·中工作量
- `get_financial_data` / `get_financial_data_by_date`: 财务(PE/PB/ROE/营收/利润/EPS)。→ 工作台「基本面」卡。
- `get_gb_info` / `get_gb_info_by_date`: 股本/流通股本。→ 封成比分母(流通市值)更准; 换手率校验。
- `get_report_data`: 研报/报告数据。→ 工作台「公告/研报」卡(摘要)。
- `get_ipo_info`: 新股信息。→ 次新股标记(梯队/打新提醒)。

### P3 中-高工作量（可选）
- `formula_process_mul_xg`: **批量条件选股**。→ 全市场自定义筛选器/选股器页(老板可自建条件扫全市场)。
- `get_full_tick` / `get_real_time_data`: 更细实时/逐笔。→ 分时/逐笔增强(盘口深度、大单追踪)。
- `get_index_stocks` / `get_trackzs_etf_info` / `get_cb_info`: 指数成分/ETF跟踪/可转债。→ 指数/ETF/转债品种扩展。
- `get_gpjy_value`/`get_bkjy_value`/`get_scjy_value`(+_by_date): 个股/板块/市场交易值。→ 板块资金/活跃度交叉。

### P4 不接（定位不符: 不做交易）
- 交易/持仓/下单: `query_stock_orders`/`query_stock_asset`/`query_stock_positions`/`cancel_order_stock`。
- 预警/推送/客户端控制: `send_warn`/`send_trade_warn`/`send_message`/`send_file`/`send_bt_data`/`send_user_block`/`exec_to_tdx`/`exec_res`。
  - 例外可选: `exec_to_tdx` 做「跳转通达信看盘」按钮(只跳转不下单), 低工作量, 老板要再加。

## 建议批次

- v0.5.92 = P2(基本面/股本/研报/新股卡 → 工作台第②步右栏)。
- P3 视老板需求排期; P4 不接。
