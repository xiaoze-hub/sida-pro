## v0.5.89 — L2 字段接入(盘中精度提升)

### P1 涨停判定切 ZTPrice + FCAmo
- 现状: live 状态机 `is_sealed` 用 `limit_rules.limit_up_price(last_close, is_st)` 自算涨停价 + `price>=limit`。ST/板块幅度靠猜, 易错。
- 改: 盘中对候选池调 `get_more_info` 取 **ZTPrice**(涨停价, 权威) 与 **FCAmo**(封单额, 万元; 官方: >0 涨停 / <0 跌停)。
  - `is_sealed` = (FCAmo > 0) 优先; FCAmo 缺失时回退 `price >= ZTPrice - tick`。
  - 封单额直接 = FCAmo*1e4(元), 替代 seal_quality_samples 的 wudao seal_amount(保留作交叉)。
- 诚实约束: FCAmo/ZTPrice 缺失 → 对应字段 None, 不编; 状态回退旧逻辑并标 `source=fallback`。

### P2 五档盘口封死/排队细分 + 盘中K用 snapshot
- 五档: snapshot `Buyp/Buyv/Sellp/Sellv`(各5档)。细分封板质量:
  - **封死**: 买一价==ZTPrice 且 买一量>0 且 卖一价>ZTPrice(卖一无压)。
  - **排队/开板中**: 买一价==ZTPrice 但 卖一价<=ZTPrice 且卖一量>0(有人在涨停价卖)。
  - **开板**: 现价<ZTPrice 且 ever_sealed。
  - 输出 `seal_quality_tag`: 封死/排队/开板/未封; 五档缺失 → None 不猜。
- 盘中K: live candle 改用 snapshot `Open/Max/Min/Now`(o/h/l/c), 替代 get_pricevol 的 O/H/L(探针未确认其携带)。定型日仍用 klines。

### P3 EverZTCount 交叉校验 + Before5MinNow 跳水/冲板
- `EverZTCount`(连板数) 与我们自推 boards 交叉: 一致→正常; 不一致→以**自推**为准(事件表口径), 但 live_day 增 `boards_vendor` 字段暴露差异, 前端不一致时标「?»tooltip 说明两口径。
- `Before5MinNow`(5分钟前价) + `Zangsu`(涨速):
  - **跳水**: now <= Before5MinNow*0.98(5分钟跌≥2%) → tag 跳水。
  - **冲板**: now >= charging_floor(=LastClose*(1+ratio*0.7)) 且 now < ZTPrice 且未封 → tag 冲板(沿用 v0.5.88 charging)。
- 输出到 live_day stocks 的 tag / 新字段 `dive`(bool) / `boards_vendor`。

### 新端点 `/api/stocks/{symbol}/l2`(单股, on-demand, 供工作台)
- 返回: snapshot{now,last_close,open,high,low,amount,inside,outside,avg,before5min, buyp/buyv/sellp/sellv} + more_info{zt_price,dt_price,fcamo,fcb,openamo,ever_zt_count,fhsl,flb,wtb,zjl,zjl_hb,l2_tic,l2_order,total_bvol,bcancel}。
- 单股接口, 前端按需调(工作台打开时), 不批量不轮询全市场; 工作台内 30s 轮询单股可接受。
- 缺字段 → None; 非交易时段返回最后交易日值并标 `as_of`(HqDate/自判)。
