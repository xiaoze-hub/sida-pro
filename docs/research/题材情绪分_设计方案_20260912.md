# 题材情绪分(情绪周期表)设计方案

> **基线**: 仓库 `xiaoze-hub/sida-pro` @ commit `2a1f1a0`(VERSION `v0.5.64`)。
> **对象**: 新建「题材情绪」能力 —— 每个通达信题材每个交易日一个 0-100 综合情绪分, 含五维明细、置信度、核心股与 20 日回看; 落库表 `theme_mood_daily`、API `/api/theme-mood/*`、前端新页「题材情绪」。
> **覆盖**: 本方案覆盖口径定义、数据基座、落库与任务、API、前端页面、测试与验收; **不含**盘中实时口径(v2)、开盘啦(wudao)题材名映射、历史成分快照与推送告警。

## 1. 背景与已定决策

老板要求按第三方产品「连板天梯」的情绪周期表形态与口径, 做我们自己的题材情绪分, 并给出完整口径说明(涨停结构 28% / 题材扩散 24% / 核心强度 20% / 接力反馈 20% / 连续性 8%, 缺失向 50 中性收缩, 置信度独立, 盘中与收盘两口径, 20 日窗口)。

已拍板的决策(2026-09-12):
1. **题材骨架 = 通达信板块体系**: 行业 128(881xxx) + 概念 457(880xxx), 含成分股与板块日线, 与站内热力图/板块详情同一套名单;
2. **本版只做收盘确认口径**, 盘中校准留 v2;
3. **新独立页「题材情绪」**(左侧导航·决策中心), 首页「情绪周期」按钮(现跳首页的旧问题)改指向新页;
4. **榜单主分用「收盘封住」**, 炸板计入接力反馈的「断板承接」;
5. 行业+概念**全参评**, 榜单只展示 Top。

技术前提已生产实测: 通达信板块日线可取(880301/881101 各 30 根); 585 个板块成分股全量约 10s; 全 A 个股日线批量(100 码/片)约 40s; 涨停事实可由日线 + 涨停规则自算(与 `limit_up_events` 同口径)。

## 2. 口径定义(唯一事实源: `src/core/theme_mood.py`)

**综合情绪分 = 0.28×S1 + 0.24×S2 + 0.20×S3 + 0.20×S4 + 0.08×S5**, 0-100 保留 1 位小数。

规则(全部维度遵守):
- 各维度先算原始量, 再用**固定锚点**映射到 0-100 → **跨交易日可比**; 不做"当日截面归一", 因此**切换窗口或题材数量不改变同一时点任何题材的分数与排名**。
- **缺失维度 → 50 分中性收缩**(该维度以 50 参与加权, 权重**不**转给其他维度)。
- 加速度不参与评分与排名。

### S1 涨停结构(28%)
`S1 = 0.40×梯队分 + 0.25×规模分 + 0.20×自身历史分位 + 0.15×同日稀缺度`
- 梯队分 = 0.6×高度分 + 0.4×连板家数分; 高度分按题材内最高板(1→20, 2→45, 3→65, 4→80, ≥6→100 线性夹逼), 连板家数分按 ≥2 板家数(0→0, 1→40, 2→60, 3→75, ≥5→100)。
- 规模分按题材当日**封住**家数(1→35, 2→55, 3→68, 5→82, 8→92, ≥12→100, 对数型夹逼)。
- 自身历史分位 = 该题材当日封住家数在自身近 60 个交易日的百分位(0-100 直接使用; 不足 60 日按实际样本并标注)。
- 同日稀缺度 = 题材封住家数 / 全市场封住家数, 映射(0→0, 2%→40, 5%→60, 10%→80, ≥20%→100)。

### S2 题材扩散(24%)
`S2 = 0.45×中位涨幅超额分 + 0.30×平均涨幅超额分 + 0.25×强涨扩散分`
- 超额 = 题材成分股涨幅(中位数/均值) − 全市场(等权同口径); 映射: −3%→0, −1%→25, 0→50, +1%→75, +3%→100(线性夹逼)。
- 强涨扩散 = 题材成分中涨幅 ≥5% 的占比 − 全市场同口径占比(单位 pp); 映射: 0→50, +3→70, +8→90, +15→100(负向对称)。
- 成分股按板块当期名单取; 停牌/无行情成分按"无数据"剔除, 覆盖率进入置信度。

### S3 核心强度(20%)
`S3 = 0.7×最高核心分 + 0.3×次高核心分`(只有 1 只核心候选则视为 1.0 权重)。
- 个股核心分 = 0.45×连板高度分 + 0.30×题材内成交额分位 + 0.25×近 5 日动量分(0-100 各子项同锚点口径)。
- 连续概率(0-1, 展示用, 不参与总分) = f(连板数, 封板质量, 量能分位): 封板质量由日线 OHLC 推导 —— 一字(open=high=low=limit)、全天封死(low=limit)、开过板(low<limit) 三档; 连板数 ≥3 且全封 → 高概率档。
- 「龙头/中军/高辨识度」= 该题材核心分 Top 个股(每题材最多取 2 只展示, 证据不足则不展示)。

### S4 接力反馈(20%)
`S4 = 0.35×晋级率 + 0.30×封板率 + 0.20×断板承接 + 0.15×昨日最高板 D+1`
- 晋级率 = 昨日该题材封住股中今日再度封住的占比(无昨日封住 → 该子项 50)。
- 封板率 = 今日该题材触及涨停股中收盘仍封住的占比(今日无触及 → 50)。
- 断板承接 = 昨日该题材涨停但未封住(炸板/断板)个股今日上涨占比(含炸板负反馈, 无样本 → 50)。
- 昨日最高板 D+1 = 昨日该题材最高板个股今日涨跌幅, 映射(−10%→0, 0→50, +10%→100)。
- 子项缺失一律 50; 全维度无昨日涨停样本时 S4=50 并在明细标注「无昨日样本」。

### S5 连续性(8%)
`S5 = 0.6×近3日结构分均值 + 0.4×稳定度`; 稳定度 = 100 − 2×近3日结构分标准差(夹逼 0-100)。历史不足 3 日 → 按实际天数; 无历史 → 50。

### 置信度(独立, 0-100 整数, 不是第二个分数)
`置信度 = 100 × (0.5×有效维度权重覆盖 + 0.3×成分覆盖率 + 0.2×数据新鲜度)`
- 有效维度权重覆盖 = 该题材非缺失维度的权重和; 成分覆盖率 = 有当日行情的成分股 / 板块成分总数; 数据新鲜度 = 取数成功且为最近交易日的比例。

### 核心题材判定(独立于总分与排名)
满足**全部**条件才标记 core: 情绪分 ≥60; 置信度 ≥70; 近 3 日中至少 2 日情绪分 ≥55 且其中至少一日封住 ≥2 只; 当日封住 ≥2 只; 接力反馈 ≥50。前三名不自动核心。

### 候选池与排序
- 候选池 = 近 10 个交易日(含当日)有过"封住 ≥1"的题材; **全部候选落库**(支持回看), 榜单只显示 Top N(默认 15, 可选 6/8/10/15)。
- 排序: 情绪分 desc → 近 3 日平均情绪 desc → 置信度 desc → 当日封住家数 desc(全平则按板块代码稳定序)。
- 左侧「当前」= 最新交易日情绪分与日变化(相对前一交易日)。

## 3. 数据基座与落库

- **题材与成分**: `src/core/tdx_boards.py` `sector_items()`(585) + `constituents(block_code)`。
- **个股日线**: TDX `get_market_data`(period=1d, dividend_type=front, 100 码/片), 取近 60 根; 同一份数据同时用于涨停判定、连板自算、涨幅分布、动量与成交额。
- **涨停判定**: 复用 `src/core/limit_up_backfill.py` 的事件抽取(规则价 → 触及/封住/一字/炸板) 与 `limit_rules`, 与库中 `limit_up_events` 同口径(当日不依赖任何外部涨停池)。
- **新表 `theme_mood_daily`**(迁移 v163, `(trade_date, block_code)` 唯一):
  `trade_date, block_code, block_name, block_type, score, s1..s5, confidence, core(bool), limit_up_cnt, touched_cnt, max_boards, ge2_cnt, core_stocks(jsonb, ≤2 只), detail(jsonb, 五维子项原始值与缺失标记), breadth(jsonb, 覆盖率/中位涨幅/强涨占比/样本数), source('close'), updated_at`。
- **任务**: cron 交易日 **15:45**(在 demon 15:35 之后), 幂等 upsert; 手动 `POST /api/theme-mood/scan/run`(后台线程, 同日重跑覆盖); `GET /api/theme-mood/scan/status`。
- **回填**: `scripts/theme_mood_backfill.py --days 40` 用同一份 60 根日线窗口一次算多日; 明确近似: **历史分位与连续性使用"当期成分"回看**(无历史成分快照, 页面与文档均标注; 后续可做成分日切面)。

## 4. API

- `GET /api/theme-mood/board?window=20&top=15` → `{trade_date, window, items:[{block_code, block_name, block_type, score, delta, confidence, core, s1..s5, limit_up_cnt, core_stocks, cells:[{date, score, limit_up_cnt}]}], coverage:{boards, with_limit_up}}`
- `GET /api/theme-mood/detail/{block_code}?days=20` → 单题材逐日五维明细、子项原始值、核心股与广度
- `POST /api/theme-mood/scan/run` / `GET /api/theme-mood/scan/status`

响应沿用统一信封 `{code, success, data, message}`。

## 5. 前端

- 新页 `/theme-mood`「题材情绪」挂左侧导航「决策中心」; 顶部标记「收盘确认」口径与数据日期。
- 结构: Top 题材榜(左, 当前分 + 日变化 + 核心标记 + 窗口切换 10/20/30) + **题材×日期矩阵**(右, 色块 = 情绪分, 单元格显示分数; 颜色用涨跌语义色阶, 遵守 UI 规则 R4/R6) + 点格子/题材打开详情(五维明细 + 子项原始值 + 核心股 + 成分覆盖)。
- 每格最多展示 2 只核心股; 证据不足不显示; 涨跌比例来自成分样本并标注覆盖率。
- 首页 `KpiBand` 「情绪周期」按钮由 `navigate('/')` 改为 `/theme-mood`。
- 纯函数(色阶映射/排序/核心标记/矩阵布局)独立成 `lib/theme-mood.ts` 并单测。

## 6. 边界与诚实降级

- 缺失维度 → 50 收缩, 明细中标注缺项; 不做编造与静默兜底。
- 无涨停题材仍可按扩散/连续性得分, 但候选池限定近 10 日有过涨停 → 榜单聚焦有接力价值的题材。
- 数据源不可用(TDX 断链) → 本次扫描不落库(保留前值), API 返回上次落库日期与 `stale` 标记; 页面显示"数据为 X 日, 本次扫描失败"。
- 本版页面口径固定标注「收盘确认」, 不含盘中数值(避免盘中数据被当作收盘阈值使用)。

## 7. 测试与验收

- 后端纯函数单测: 各维锚点映射边界、缺失收缩(权重不转移)、核心判定边界(60/70/55/2 只)、排序稳定性(同分四级比较)、跨日可比性(题材集合变化不改分数)。
- 落库: 幂等(同日重跑覆盖)、回填多日不越界、TDX 失败不落库。
- API 契约测试(信封/参数校验/空态)。
- 前端: `lib/theme-mood.ts` 纯函数测试 + 矩阵/榜单组件测试(空态/缺数据/核心标记) + 现有门禁(vitest / tsc / eslint / UI-RULES / build)。
- 生产验收: 回填近 20 个交易日 → 人工核对 Top 题材与当日强势题材一致(如 09-11 元件/电力/通信设备) → 浏览器走查榜单/矩阵/详情 → 与老板截图形态对齐。

## 8. 明确不做(v1)

盘中实时口径与盘中校准(v2); 开盘啦(wudao)题材名映射; 历史成分快照(前视偏差如实标注); >30 日窗口与自定义题材; 推送/告警; 与现有 `market_phase`(全市场情绪周期)合并口径。
