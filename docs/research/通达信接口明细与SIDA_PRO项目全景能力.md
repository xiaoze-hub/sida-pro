## 一、 通达信（TQ）客户端接口能力完整清单与接入情况

通达信本地行情网关（部署于局域网 `172.27.16.1:17709`）通过 JSON-RPC 暴露底层 `tqcenter` 原生函数。经全仓源码审计，全网关共支持 **62 个原生接口**，当前在 SIDA-Pro 中已深度落地 **24 个核心接口**，明确不接 **18 个写入/交易接口**，其余作为预留中间件。

### 1. 已接入且作为生产核心支柱的接口（24 个）

| 接口名称 | 接口用途与数据定义 | SIDA-Pro 对应模块 / 落地能力 |
| :--- | :--- | :--- |
| **`get_more_info`** | 个股高频微观盘口：委买/委卖总量、撤买/撤卖量、主力净流入、涨停价、跌停价、封单金额、竞价金额(`OpenAmo`)、竞价量比(`OpenVolPre1`)、竞价涨幅(`OpenZAF`) | ① **集合竞价专区 (`/auction`)** 穿透量比与真实竞价金额；<br>② **撤单意图引擎 (`cancel_order_intent.py`)** 识别虚假托盘；<br>③ **盘口二级标签 (`L2Tab.tsx`)** 撤单率与主力买卖量。 |
| **`get_market_data`** | 历史日K、周K、月K、分钟K线序列（OHLCV + 成交额） | **K线核心主图 (`KlineChart.tsx`)**，多周期K线平滑渲染。 |
| **`get_market_snapshot`** | 实时盘口快照：五档买卖价量、最新成交价、现量、分笔 | **个股工作台顶部 Band1** 实时快照行情与秒级价格跳动。 |
| **`get_pricevol`** | 批量股票价量：批量拉取现价、昨收、成交量、成交额（500只/片仅需 0.07s） | **全市场快速扫盘器 (`market_scan.py`)** 与自选股秒级轮询。 |
| **`formula_process_mul_zb`** | 批量执行客户端指标公式（如 MACD、KDJ、SSRP、MCST、CYC 等） | **个股筹码体检 (`tq_chips.py`)**，提取通达信原生筹码峰与市场成本。 |
| **`formula_process_mul_xg`** | 批量执行客户端条件选股公式（直接在客户端高性能筛选全市场） | **机会页选股工具 (`Opportunities.tsx`)**，支持复杂形态全市场扫票。 |
| **`formula_zb_single`** | 单股指标公式全序列输出 | **趋势操盘线与牛熊线 (`pioneer-indicators.ts`)**，输出全历史指标序列。 |
| **`get_trackzs_etf_info`** | 指数对应跟踪 ETF 列表（现价、规模、份额、IOPV 实时净值） | **主线题材复盘 (`ThemeMood.tsx`)** 300ETF IOPV 折溢价雷达卡。 |
| **`get_match_stkinfo`** | 证券跨市场智能检索（代码 ↔ 名称，支持 A股/港股/ETF/转债） | **全局搜索与快捷指令 (`CommandPalette.tsx`)**，跨市场秒级联想。 |
| **`get_stock_list`** | 全市场代码表拉取（沪深北五大市场全量股票清单） | **全市场 Universe 股票池构建 (`universe.py`)**。 |
| **`get_sector_list`** | 全市场行业、概念、地域板块代码与名称列表 | **板块热力大屏 (`Heatmap.tsx`)** 与题材情绪分类基础。 |
| **`get_stock_list_in_sector`** | 指定板块下的全部成分股代码拉取 | **题材龙头身位拆解 (`theme_mood.py`)** 与概念成分反查。 |
| **`get_relation`** | 个股所属板块/概念反查映射关系表 | **个股工作台右栏 QuickRail** 的题材/板块标签（Chips）。 |
| **`get_divid_factors`** | 分红送配与除权除息因子数据 | **K线前复权计算 (`kline_adjust.py`)**，避免复权污染。 |
| **`get_gb_info`** | 股本变动信息（总股本、自由流通股本） | **换手率真实计算** 与 **封单成色分母（流通市值）精确换算**。 |
| **`get_financial_data`** | 专业财务分析数据（PE(TTM)、PB、ROE、净利润、营收增长率） | **基本面二级标签 (`FundamentalTab.tsx`)** 财务深度排查。 |
| **`get_financial_data_by_date`** | 指定历史报告期/日期的精准财务快照 | **历史归因与历史基本面对比**。 |
| **`get_kzz_info`** | 可转债全量行情与正股转股价、溢价率数据 | **可转债套利与股债联动监控模块**。 |
| **`get_ipo_info`** | 新股发行与上市首日详细数据 | **次新股识别与连板梯队剔除/标记**。 |
| **`get_scjy_value`** | 市场交易统计总量（全市场成交金额、上涨/下跌家数） | **大盘环境温度计 (`market_phase.py`)**。 |
| **`get_gpjy_value`** | 个股交易衍生统计值 | **个股流动性与异常成交放大检测**。 |
| **`get_bkjy_value`** | 板块交易统计值与资金进出流向 | **板块热度与主线轮动强度评估**。 |
| **`download_file`** | 驱动客户端静默下载经营分析与深度报告文件 | **后台数据定时同步与预热脚本**。 |
| **`refresh_cache`** | 强制刷新客户端行情本地缓存 | **盘前与开盘时段数据强制对齐**。 |

### 2. 明确排除不接的接口（18 个，定位不符或有安全副作用）

| 接口名称 | 官方定义 | 排除理由（红线管控） |
| :--- | :--- | :--- |
| **`order_stock`** | 股票真实下单委托 | **系统红线**：定位为纯分析与决策支持系统，严禁任何自动实盘下单行为。 |
| **`cancel_order_stock`** | 股票真实撤单委托 | 交易执行接口，定位不符，坚决不接。 |
| **`stock_account`** | 券商资金账户登录与状态查询 | 需暴露用户券商交易密码，涉及资金安全风险。 |
| **`query_stock_asset`** | 查询账户总资产、可用资金、市值 | 账户资产同步接口，目前统一由模拟盘与交割单体系承接。 |
| **`query_stock_orders`** | 查询当日委托订单明细 | 交易级接口，不予接入。 |
| **`query_stock_positions`** | 查询证券持仓明细 | 交易级接口，持仓管理由本地数据库隔离承接。 |
| **`create_sector`** | 在客户端创建自定义板块 | **禁止有副作用的写入**：严禁修改用户的通达信本地配置。 |
| **`rename_sector`** | 重命名客户端自定义板块 | 客户端环境写入，不符合只读原则。 |
| **`delete_sector`** | 删除客户端自定义板块 | 破坏性不可逆操作，坚决不接。 |
| **`clear_sector`** | 清空客户端自定义板块内容 | 破坏性不可逆操作，坚决不接。 |
| **`send_user_block`** | 推送自选股覆盖客户端自选板块 | 写入客户端，易破坏用户原有通达信自选分组。 |
| **`send_bt_data`** | 回传策略回测数据至通达信客户端界面 | 回测数据直接在 SIDA Web 大屏渲染，无需逆向推给通达信。 |
| **`send_file`** | 向通达信客户端发送本地文件 | 客户端控制类接口，无数据分析价值。 |
| **`print_to_tdx`** | 向通达信控制台打印日志 | 客户端调试输出，服务端运行无意义。 |
| **`send_warn`** | 向客户端推送预警弹窗 | 预警由 SIDA-Pro 原生微信/多渠道通知网关独立承发。 |
| **`send_message`** | 向通达信发送客户端消息 | 纯客户端 UI 交互，不予接入。 |
| **`exec_to_tdx`** | 调用通达信客户端按钮点击/窗口操作 | 存在不可预期的客户端 GUI 副作用。 |
| **`subscribe_hq`** | 订阅行情 WebSocket 回调 | **架构限制**：当前局域网网关为无状态 JSON-RPC 桥，不支持反向 HTTP 回调。 |

### 1. 行情与深度技术分析模块

1. **个股大屏作战工作台 (`/stocks/:symbol`)**：
   - **K线绝对主角（≥80% 屏宽）**：拒绝卡片堆叠，采用 Lightweight Charts v5 打造超宽专业图表区；
   - **K线主图横向筹码分布山形图 (CYQ 直方图)**：自顶向下还原 120 交易日真实波段换手沉淀，红柱获利、蓝柱套牢、金黄色高亮并标示 `◀主峰`；
   - **K线双线成本标记**：
     - 🔴 **`主力成本线 (实线)`**：回踩不破即为防守底线；
     - 🟡🟢 **`70%成本顶沿/底沿 (虚线)`**：主力核心建仓密集箱体；
   - **威科夫量价结构图层**：全自动识别放量突破、弹簧针试探（Spring Probe）、放量滞涨与缩量沉淀；

2. **主线题材复盘与情绪周期 (`/theme-mood`)**：
   - **连板梯队 2D 矩阵视图**：实时穿透停牌日（如新华传媒连板识别），横向展开市场高度板与断板风险；

## 三、 总结与后续扩展建议

当前 SIDA-Pro 已将通达信 TQ 的核心行情与高频指标（`get_more_info`、`get_pricevol`、`formula_process_mul_*`、`get_trackzs_etf_info`）发掘并深度装配到业务中，成功解决了：
1. **盘后与集合竞价数据真实性问题**（告别 `--` 横杠）；
2. **主力从建仓以来的筹码峰图形化呈现**（CYQ 横向直方图）；
3. **超短交易 9:25 决战窗口决策盲区**（五态意图研判与妖股先锋）。

**未来可进一步借力的通达信技术点**：
- 探索 `formula_process_mul_xg` 开放用户自定义公式脚本；
- 扩充可转债正股与转债折溢价联动套利模块。
