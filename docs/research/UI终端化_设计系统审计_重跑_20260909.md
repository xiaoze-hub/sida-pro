## 3. P0 复核明细

### 3.1 Quote 路由化：达成，残项收窄

- 路由：`/forecast`、`/quote`（query `?symbol=`）+ 本波新增 `/quote/:symbol`（路径式，PermGuard `view_forecast`）；QuotePage 内做 path→query 参数规范化。
- 主视图：KlineChart 内嵌（非 Dialog），宽度占比达标。
- **残项**：StockInsightModal 仍是弹窗预览形态——但本波已加「全屏行情」按钮（桌面端带文字、移动端图标）直达 `/quote/:symbol`，形成"弹窗速览 → 全屏终端"出口；`biz-ui/components/KlineModal.tsx` 为死代码（无引用，待删）。

### 3.2 Opportunities 去卡片化：本波完成

列表区改为表头(桌面端 9 列：标的/动作/评分/入场/止损/目标/来源/操作) + 扫读行（`role="button"` 可键盘操作、`aria-expanded`）+ 点击展开明细（完整信号文本、失效/策略/来源、因子解释 chips、组合约束、反馈操作）。移动端保留名称+动作，三要素在展开区补齐。

### 3.3 响应信封：已全量采纳

全站走 `@panwatch/api` fetchAPI（`{code,success,data}` 解包 + 30s GET 内存缓存 + 401 单飞登出）。现存 10 处裸 `fetch(` 均为合法旁路：4 处导出下载（blob）、2 处报告 HTML/PDF 沙箱预览、1 处 WebSocket、其余为同类二进制/流场景，无需迁移。

## 4. 数据层：TanStack Query 引入（W3.7）

- `src/hooks/useApiQuery.ts`：useApiQuery/useApiMutation 薄壳；queryFn 固定 `cacheMode:'reload'` 绕开 fetchAPI 内置缓存（TanStack 是唯一缓存所有者，避免 mutation 后拿到旧值）；`registerQueryClient`/`clearQueryCache` 供登出流程清缓存。
- `main.tsx`：QueryClientProvider，全局 staleTime 30s / retry 1 / refetchOnWindowFocus false。
- 已迁移：Audit（['audit', user]）、Reports（['reports']，items+jobs 单请求）、Profile（['profile'] / ['profile','stats']，PUT 后 setQueryData 就地更新）。
- 度量：`const [loading` 31 → **28**；`useState.*loading` 剩 **1**（Reports 弹窗内容一次性加载，非服务端列表状态）；136 处 setLoading/setError 中列表页手写 try/finally 模式随迁移递减。
