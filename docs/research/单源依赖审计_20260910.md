## 0. 执行摘要

- **机制分三层**：`Engine`（DB 优先级链 failover，首个非空即返回）→ `registry`（各数据类型合法 vendor 表）→ `DATA_SOURCE_SEEDS`（默认启用/优先级）。绝大多数 quote/kline/news/资金流/两融/龙虎榜类路径有 2~8 源链，健康。
- **单源路径约 30 条**，归三类：① 注册表/seed 级单源（board_capital_flow / market_capital_flow / events / northbound / macro_calendar / wenda / chart）；② **绕过 Engine 的硬编码单源**（指数行情=腾讯、分钟K线=腾讯 ifzq、dark-flow=腾讯、orderbook/seal/auction/thsdk 全家桶、discovery 热榜=东财、财经日历=ftshare、个股公司资料=zhitu、大盘资金网关=硬编码 IP）；③ 本地文件/落库派生（dark-flow-tq 文件、l2_ticks、seal 样本）。
- **静默空白判据** = 单源 + 失败态为 `[]`/`{}`/null 且无任何文案。命中 🔴 的有：`/market/indices`（已修）、`/quotes/minute`（文案误归因）、`/stocks/quotes`（吞异常）、`/market-data/board-capital-flow`（空列表）、`/news`（超时置空）。
- **本次已修 2 条**：① 指数行情补链（腾讯 → 新浪，覆盖 CN/HK/US 全部 6 只首页指数，实测通过）；② `/market/indices` 由静默 `[]` 改显式 502，前端既有 ErrorBanner 直接给出"大盘指数 · 不可用 + 重试"。
- 遗留清单与优先级见 §4；机制细节与全量路径表见 §1/§2。

## 1. 机制速写（判源数的依据）

### 1.1 Engine 主备链（packages/marketdata/src/marketdata/engine.py:62）

- 源列表来自 `DbConfigProvider.sources_for(datatype, market)`（src/core/marketdata_client.py:36），按 `priority` 升序逐个尝试；
- 单源超时 `MARKETDATA_VENDOR_TIMEOUT` 默认 8s（engine.py:43）→ 跳下一个源；
- 429/401 类错误走 KeyPool 换 key（engine.py:117-133）；**空结果也跳下一个源**（engine.py:148-151）；
- 全链失败 → `Response(ok=False, data=None, error=...)`（engine.py:161）——**是否"静默"取决于端点如何映射这个失败**。

## 3. 单源清单与处置决策

**处置原则**（写死供后续遵守）：
1. **能补链就补链**：同语义第二源存在且可达 → 接进链（本例：指数行情）；
2. **补不了就显式**：无第二源或接入成本高 → 失败态必须带"原因 + 可重试"，**禁止 `[]`/`{}` 装作没有数据**；
3. **数据缺失优于数据错误**：单位口径未对齐等场景返回 null（对齐 W1.1 约定），不做静默换算。

| 单源路径 | 决策 | 状态 |
|---|---|---|
| 指数行情（market/indices + 指数详情 + 报告/盘前/快照等 6 处消费） | **补链**：腾讯 → 新浪（CN 全格式 / 港指 hkHSI / 美股 gb_$） | ✅ 本次完成 |
| 同路径失败残余 | **显式降级**：双源全空 → 502，前端 ErrorBanner 重试 | ✅ 本次完成 |
| 分钟K线（腾讯 ifzq 硬编码） | 待办：显式降级字段（文案归因）+ 评估落库 1m 兜底 | §4-P1 |
| 自选批量行情 /stocks/quotes | 待办：逐市场失败汇总为显式标记 | §4-P1 |
| 板块资金 board-capital-flow | 待办：空态显式化（东财备源海外 502，补链价值低） | §4-P1 |
| /news 超时置空 | 待办：超时 ≠ 无新闻，返回 degraded 标记 | §4-P1 |
| board_capital_flow / market_capital_flow / events / northbound | **接受单源**：无同语义第二源（东财北向已断供在案）；失败已 502 → 保持 | ✅ 记录 |
| more_info / dark-flow-tq（TQ 系） | **接受单源**：TQ 扩展指标 by design；端点已给 404 + 原因 | ✅ 记录 |
| thsdk 全家桶（L2/盘口/竞价/封单/问小达） | **接受单源**：A 股 L2 唯一来源；均已有 `available/warnings` 显式语义 | ✅ 记录 |
