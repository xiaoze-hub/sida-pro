# 第 2 波

## L2-A｜B1 首页三明治（P0，最高风险，必须截图验收）

**文件**：`frontend/src/pages/Dashboard.tsx`（主，实测该页组件都在此单文件内，无 `components/dashboard/` 目录）

**现状（实测）**：首屏 1268 个文本叶子节点，10px 占 34%；标题 20px 与指数点位 20px 同级；无任何一句「今天该干什么」。

**要求**
1. **结论层**（首屏顶部，唯一新增结构）：1 句非数字结论 + 3 个 28px 数字（情绪值 / 涨跌家数 / 主线）。数字用 `.font-num` + `tabular-nums`。
2. **证据层**：现有卡片保留，但每卡只留「1 数字 + 1 方向箭头 + 1 句短语」；其余内容进该卡右侧抽屉。
3. **细节层**：其余模块默认折叠，标题「展开更多数据」，展开状态记 localStorage。
4. 首屏 `y<900` 内数字总数 ≤9 个。
5. 「修复 / 情绪周期」不用紫色数据色（紫仅用于交互）；合规长句（`主力净流入: 通达信 SUPAMO 全市场汇总...`）移入 `?` 提示。
6. **禁止**：删掉任何现有数据模块；改动任何后端接口；动 `get_main_intent` 相关调用。

**验收（全部可测）**
- 首屏 `y<900`：数字 ≤9、文本块 ≤80、含 ≥1 句非数字结论
- 截图 3 档：1280×800 / 1440×900 / 1920×1080，人工确认结论层不被折叠、不与指数卡重叠
- 折叠状态刷新后保持
- `tsc / eslint / check_ui_rules / vitest` 四绿；`price_bg` / `accent_alpha` baseline 不得上升

**测试**：新增 `frontend/tests/components/dashboard-sandwich.test.tsx`
①结论层必须渲染且含非数字句子；②首屏数字计数断言；③折叠开关持久化；④缺数据时结论层显式「无数据（原因）」而非隐藏。

## L2-F｜G11 `Term` + G13 `EmptyState` 两个共享组件（纯新增，3 批依赖）

**文件**：新建 `frontend/src/components/Term.tsx`、`frontend/src/components/EmptyState.tsx`
（放 `components/` 根，与既有 `PromotionFunnel.tsx` / `ThreeTierVerdictRow.tsx` 同层；`frontend/src/components/ui/` 目录**不存在**，不要新建）

**`Term`**
- 虚线下方 + `?`，hover/focus 出 1 句人话；`children` 为原文，`def` 为解释；支持 `href` 跳口径文档。

## L2-G｜G1 字号收敛 + R10b 棘轮（**产品已批准**，2026-10-24）

**文件**：`frontend/scripts/check_ui_rules.mjs`（在 `frontend/` 下调用，实际路径 `scripts/check_ui_rules.mjs`）、新建 `scripts/ui-rules-font10-baseline.json`、`frontend/src/index.css`（如需 `--fs-*`）

**背景（实测）**：`text-[10px]` **730 处**、`text-[11px]` **968 处**；门禁 `FONT_ALLOWED = {10,11,12,13,16,20}`。
审计 G1 想直接收敛到 `{12,13,16,28}` —— 那等于一次动 **1698 处**，一个 lane 做不完也无法目检。

**本 lane 只做第 1 步：建棘轮止血（不改任何视觉）**
1. 在 `check_ui_rules.mjs` 新增规则 **`R10b-FONT-10-RATCHET`**：按**文件**统计 `text-[10px]` 出现次数，
   基线写入 `scripts/ui-rules-font10-baseline.json`（初始值 = 当前每文件计数，用脚本生成，不许手敲）。
2. 判定：`当前 > 基线` → **红**（新增 10px 即失败）；`当前 < 基线` → 打印「可调低 baseline」；
   文件降到 0 → 提示「可从 baseline 删除」。
3. 与既有 `R10-FONT-SCALE` 并存，职责分离：R10 管「有没有非法档位」，R10b 管「10px 有没有变多」。

**产出生成的基线示例**
```json
{
  "src/pages/Admin.tsx": 128,
  "src/pages/Dashboard.tsx": 96,
  "_note": "2026-10-24 建立。规则: 每文件只减不增。收敛完成后连同 FONT_ALLOWED 的 10 一起移除。"
}
```

**验收**
- `node scripts/check_ui_rules.mjs` 在**未改任何页面**的情况下跑出 `UI-RULES OK`（基线覆盖全部现状）
- 故意在任一文件加一个 `text-[10px]` → 该文件红；撤销 → 绿（变异验证）
- 基线文件里不得有手写的估算数字（必须是脚本统计结果）

**禁止**
- **本 lane 不许改任何 `.tsx` 的字号**（视觉改动留给第 2/3 批各页 lane 捎带）
- 不许为了过门禁把基线数字调高

**后续两步（写进各页 lane，不在本 lane 执行）**
- 第 2 步：每个改页面的 lane 必须把该页 `text-[10px]` 收到只剩「图表轴标签 / 时间戳 / 数据源指纹」三类元数据，其余 ≥12px；结论数字 ≥20px；每降完一个文件调低基线。
- 第 3 步（最后一批）：全仓 10px 归零后，才把 `FONT_ALLOWED` 改 `{12,13,16,28}` 并同步更新
  `docs/design/20261023_01_design_tokens.md:473` 的铁律原文。**在此之前铁律原文仍有效**，各 lane 不得以「铁律允许 10px」为由拒绝收敛。
