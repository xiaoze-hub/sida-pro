> **基线标识**：`v0.51.0`（本地 dev，`integration/ui-batch-20261024` 之后的工作树；线上同源数据）。走查时间 2026-10-24，账号 admin，视口 1440×900，Playwright 实测 + DOM 样式采样。
> **对象路径**：线上路由 `/analysis/:symbol/:date`（`frontend/src/App.tsx` 的 `AnalysisDetailPage`，`PermGuard perm="view_reports"`）；对应源码 `frontend/src/pages/AnalysisDetail.tsx`。

## 入口事实（先纠正一个走查难点）

`/history` 里多数记录点进的是「目录 + 正文」双栏阅读器，**不会**进 `/analysis/:symbol/:date`；只有 `agent_name === 'tradingagents'` 且带 `stock_symbol` 时才 `navigate()`（`History.tsx:301-302`）。所以直接拼 URL 是有效的进入方式，但**大量记录根本没有这个路由的页面**——审计原文把它当通用详情页是不准确的。

## 四个必查项（逐条给实测）

### ① 正文是否 13px / 1.6

**不是 13px，但比 app 其他页更适合长文阅读。**

- 该页正文（报告段落）字号分布：`14px` 621 个节点、`16px` 668 个节点；壳层（侧栏/按钮/说明）才是 10/11/12px（151/218/177 个）。
- 行高实测 `{22px, 26px, 16.5px}`：`16px` 文本配 `26px` ≈ **1.63**，`14px` 配 `22px` ≈ **1.57**，均接近 1.6，长段落可读。
- 结论：**正文排版合格，不用改**；反而「其它页 10px 正文、这里 14/16px 正文」说明字号体系是两套，收敛时别把这里拉小。

### ② 是否有目录吸顶

**有，且在右侧**。实测 sticky：`目录 / 二级目录` 常驻右侧栏，含「PM 最终决策书 / 技术分析师 / 一~九节」完整目录。
- 目录默认只显示一级，「二级目录」开关展开后条数翻倍，没有滚动上限，长报告会出现目录比正文长的情况。
- 建议：目录容器加 `max-height` + 内部滚动 + 当前节高亮（现在没有当前位置指示）。

### ③ 图表可否放大

**不能一键放大。**

- 该页有 **11 个 canvas**（K 线 + 副图），lightweight-charts 自带滚轮缩放可用，但**没有「放大 / 全屏」按钮**，只提供「分享图」「导出 PDF」。
- 同屏还有工具栏 15 个指标按钮（1分…月K、成交量/MACD/买卖比/情绪/活跃度/分时/筹码分布），与首页 K 线同样拥挤。
- **标注遮挡复现**：K 线右侧「70%成本阻力 / 主力成本上沿 / 筹码峰(占5.6%) / 套牢分界(成本90%) / 主力成本下沿」等 7+ 个色块标签挤在同一竖排，互相压字（截图 `analysis-fold.jpg`）。
- 建议：加「全屏」按钮（复用已有 `focus-mode`，`index.css` 已有 `html[data-focus-mode]` 规则），标注默认只留最近 3 个（与 `marker-limit` 同一套）。

### ④ 失败态是否有出口

**有基本出口，但缺下一步。**

- 空态文案：`未找到 600111 在 2026-10-23 的深度分析记录` + `返回` 链接，页面不报错、不白屏，属合格空态。
- 缺：**日期/标的切换器**（只能手改 URL）、**「重新生成」或「去报告中心生成一条」按钮**（现在只能返回）。
- 建议：空态给「返回报告中心」+「换一天（最近有数据的日期）」两个动作；有数据日期由 `/history?agent_name=tradingagents` 提供，别让用户猜。

## 额外发现（优先级高于上面 ③ 的部分）

1. **底部固定免责条再次遮住内容**（截图可见）：「主力意图 … 获利 94% …」这一行被固定条压住一半。与全站 G10/R8 同源，本页也需要 `--disclaimer-h` 补偿。
2. **置信度 `6.0 / 10` 没有解释**：读者不知道 6 分算高算低、由什么组成。建议加一句「满分 10，≥7 才考虑行动；由证据一致性/覆盖度合成」（若口径如此），或链接到口径说明。
3. **目录与正文比例失衡**：目录 9 节 + 二级全开，右侧栏占了约 1/4 屏宽；建议默认只显示 3 个核心节（最终决策书 / 风控裁决 / 技术分析师），其余折叠。
