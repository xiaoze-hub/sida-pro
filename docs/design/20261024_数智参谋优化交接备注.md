## 2. 产品铁律（违反会被打回，不是风格偏好）

- 定位是**行情终端、看图决策**，不是数据看板；**不做数据堆砌**
- **K 线是绝对主角（≥80% 屏宽），外面不许包卡片**
- **去卡片化**：`hairline`（1px 分隔线）取代边框与卡片底；`.shadow-float` **全站只允许 1 处**（框选即问浮条）
- **买红卖绿**（A 股惯例）；字号**只允许 10/11/12/13/16/20**；数字必须 `tabular-nums`；金额/量自动「亿/万」
- **不做大盘涨跌方向预测** —— 方向判断交给人，AI 只做情报备料
- 指标缺失**必须显式标「无数据」**，禁止 LLM 推测或编造数字
- 提统计胜率必须同时给三件套：**样本数 + 同池无条件基准 + 是否剔除 T+1 一字涨停**，否则不许写成能力

## 9. 协作纪律（都是踩过的坑）

- **用 `git worktree`**，不要在人家的 checkout 里切分支（多人/多 agent 会互相踩丢改动）
- **禁止跑全量 `pytest tests/`** —— 单进程要 20+ 分钟，会把你卡死；只跑定向。发版前的 4 分片全量由主控跑
- **venv 用 `/home/ubuntu/sida-pro/.venv/bin/python`**，不要用 `/home/ubuntu/sida-src/.venv`（那是**另一个仓库** sida-src，不是本项目）
- 命令前缀一律 `env -u PYTHONPATH`
- worktree 里没有 `node_modules`，需要先 `cd frontend && corepack pnpm install --frozen-lockfile`
- 前端改动必须跑 `npx tsc --noEmit`；改了组件还要跑对应 vitest
- **改完必须自己 `git add` + `git commit`**（本批已有 2 个子代理忘记 commit，被主控补的）
- 每个 commit 必须带 `CHANGELOG.md` 条目（`VERSION` / README 双徽章只在发版 commit 改）
