## 1. 结论

可读性、层次、交互反馈三类问题**不是个别页面写坏了，而是全局基线的数值定错了**：全站 87% 的文字 ≤12px，卡片边界对比度 1.19:1，可点元素零 hover 反馈，专业术语零解释。个别页面（数智参谋、设置、影子账户、开发者文档、档位）其实已经证明设计系统能做对——问题在于基线没被强制。

因此改进顺序应是：**先改 5 个全局基线（§2），再改 8 个高频页面的结构（§3 中标 P0 的），最后才是长尾页面**。只改单个页面而不动基线，会立刻被基线拉回原样。

## 3. 分模块分析

> 每模块格式：**定位 → 结构 → 问题 → 改进 → 优先级**。标 ★ 的是小白首次进入最可能落地的页面。

### A. 公开入口

#### A1. 官网落地页 `/`（未登录）
- **定位**：拉新/介绍，含「一切皆接口」主张、三大能力卡、调用示例、CTA。
- **结构**：顶部 logo + `tiers/docs/login/register` → 主视觉（ASCII 星号图案 + `[ AI-POWERED ANALYSIS PLATFORM ]`）→ 卖点 → 3 张能力卡 → 设计思路 → 调用示例 → CTA → 页脚。
- **问题**：①主视觉的 ASCII 图案在暗色下像排版事故，首次访客读不出「这是什么产品」；②首屏同时给「快速体验 / 源码安装 / 注册 / 免费注册 / 阅读文档」5 个等价 CTA，没有唯一主动作；③「SIDA 开发者预览版面向全球开发者开放」与「给盯 A 股的开发者与操盘手」两句话受众不一致（开发者 vs 操盘手）；④全站唯一的「小白」入口——「快速体验」——没有说明点进去看到什么。
- **改进**：首屏只留 1 个紫色主按钮「免费开始（30 秒）」+ 1 个次按钮「看一个真实示例」；ASCII 图案换为产品截图（带暗色遮罩与 3 个标注点）；受众句统一为「给 A 股散户与小团队的 AI 分析工作台」；能力卡加「点这里能看到什么」的一句话结果描述而非功能名。
- **优先级**：P1

#### A2. 登录页 `/login`
- **定位**：密码/验证码/注册/忘记密码 四合一。
- **问题**：①副标题「A股智能分析 · AI 全链路打通」是内部口径，用户读完仍不知道能干什么；②「密码登录/注册/验证码登录/忘记密码」四个页签并列，下方又重复一个「忘记密码？」，四选一的信息结构对首访者是干扰；③主按钮紫 `#5252e0`（实测，白字 5.7:1 达标）已经是全站强调色，但它同时承担「选中页签/链接/按钮」三种语义，登录页内就能看到三种用法；④「注册」为邀请制（`/api/auth/status` 返回 `register_mode: invite`），但页面未提示，用户点进去才发现需要邀请码；⑤无「没有账号？先看看能做什么」的软着陆路径。
- **改进**：强调色保持 `#5252e0`（白字 5.7:1 已达标），只把**紫色文字**（情绪周期值、主线值）换成中性白或 `#7b7bf0`，避免「紫色=可点」与「紫色=数据」混淆；副标题改为价值句（「3 秒看懂今天市场该不该动手」）；页签精简为「登录 / 注册」两项，验证码与忘记密码降级为文字链；注册页提前标注「内测邀请制，可申请」；补一行「先随便看看 →」到落地页。
- **优先级**：P2

#### A3. 档位页 `/tiers`
- **定位**：免费 vs Pro 的能力对照。
- **问题**：①这是全站**字号最健康**的页面（标题 28px、正文 13px、行距舒适），可作为反面教材正例；②「内测期不收费」红字与「Pro 需提交申请」混排，行动指令弱；③能力项只有勾，没有「我为什么要它」。
- **改进**：保留排版，仅补两处——每档顶部加一句「适合谁」；锁定项右侧「更高档位没有」改为按钮「申请 Pro」。
- **优先级**：P2

#### A4. 服务条款 `/terms`
- 结构清晰（一、二、三编号 + 免责声明），13px 正文，无明显问题。仅建议顶部加「最后更新」吸顶，长文加目录。
- **优先级**：P2

### B. 行情域

#### B1. ★ 首页 · 驾驶舱 `/`
- **定位**：全站默认落地页，聚合市场情绪、指数、主线、温度、资金、共振。
- **结构**：源心跳行 → 标题「市场全景 · 组合工作台」+ 新手引导/看板定制 → 市场情绪一句话条 → 5 张指数卡 → 4 张指标卡 → 情绪周期阶段 | 市场主线 | 市场温度（三列）→ 大盘资金流 | 三指标共振 | 全市场涨跌分布 | 快讯（多段）。
- **问题**：
  1. **P0 无结论**：首屏 239 个文本块 / 120 个数字，没有任何一句「今天该干什么」，标题 20px 与指数点位 20px 同级。
  2. **P0 层级不可见**：三列卡片全靠 1.19:1 边框分隔，视觉上是一整块黑。
  3. **P1 颜色失义**：红既表示「涨」又是「修复」态的主色（`#e53935` 出现 127 次），紫 `#5252e0` 同时是选中态与「情绪周期/主线 Top1」的数据色。
  4. **P1 认知过载**：「修复 · 第 5 天 / 高度 6 / 首板 73 / 晋级 100% / 段数 4 / EMA α=1/3 + 2 日确认」一次给 12 个概念，且无一个可点开解释。
  5. **P1 空值误导**：「封板率 --」与「3 档/2 档」同排，用户无法区分「没数据」与「值是 0」。
  6. **P1 合规长句占首屏**：「主力净流入: 通达信 SUPAMO 全市场汇总(资金面参考, 禁用于主力意图判定)」10px 长句贴在数据条右侧。
- **改进**：
  1. 首屏改为**三明治**：结论层（一句话 + 3 个 28px 数字：情绪值 / 涨跌家数 / 主线）→ 证据层（6 张卡，每卡「1 数字 + 1 方向箭头 + 1 句短语」）→ 细节层（其余模块默认折叠，标题「展开更多数据」）。
  2. 首屏数字上限 9 个；3 个结论数字用 `--font-num` 28px/700。
  3. 卡片套用 G4 三档色 + G5 hover，可点开右侧抽屉看详情。
  4. 「修复 / 情绪周期」改用中性色标签 + 走势小图，不用紫色数据色。
  5. 合规长句移入 `?` 提示与页脚。
- **优先级**：P0

#### B2. ★ 个股 / 指数工作台 `/stocks/:symbol`
- **定位**：K 线 + 盘口资金 + 建议 + 基本面 + 消息 + 研究 + 预测 七合一。
- **结构**：标题区（名称/代码/价格/涨跌幅 + 13 项行情指标两行）→ 建议条（观望·评分 40·技术面中性）→ 顶部 15 个指标按钮 → K 线主图（含 G/S 标注、筹码分布浮层）→ 子页签 6 个。
- **问题**：
  1. **P0 图表可读性差**：15 个指标按钮（1分/5分/…/120根K线/成交量/MACD/买卖比/情绪/活跃度/暗盘资金/分时/筹码分布）高度约 20px，选中/未选中仅靠底色微差；图上「红三兵 / 多方炮 / 单阳不破 / 弹黄试探」等标注互相叠压，10px 字压在 K 线上不可读。
  2. **P0 浮层堆叠**：右侧「筹码分布(CYO)」浮层常驻覆盖 1/3 图宽；右下角另有「多空博弈·区间待方向」浮卡 + AI 球 + 免责条，四者同挤一个角。
  3. **P1 指标墙**：今开/最高/最低/成交量/成交额/振幅/换手率/量比/总市值/流通市值/PE(动)/PE(TTM)/PB 共 13 项 10px 平铺，小白无法判断「哪个先看」。
  4. **P1 子页签与图表争空间**：盘口资金/建议/基本面/消息/研究/预测 6 个页签放在图表下方，需要滚动才能发现。
- **改进**：指标按钮分两组（周期 / 叠加），每组 1 行 4-5 个、高度 28px、选中态实心紫；图表标注改为「默认关闭 + 开关打开后只显示最近 3 个」；筹码分布改为可折叠右侧栏（不覆盖画布）；13 项指标收成 5 项首显 + 「全部指标」展开；子页签上移到标题右侧与「首页」同层；右下角只保留一个悬浮元素。

#### B3. ★ 板块热力图 `/heatmap`
- **定位**：行业/概念 treemap，点击下钻成分股。
- **问题**：①小方块内的 10px 文字被裁断（「工业金属(+2.13% [涨停 1]…」），右侧密集小格完全不可读；②顶部四个按钮「行业 / 概念 / 面积=量能 / 面积等权」——前两个是分类，后两个是排序方式，却排成同一排同样式；③颜色只有红/绿，没有图例说明「±3% 为平盘灰」；④说明文字一整行 10px 灰字承担了图例 + 交互提示 + 口径说明三件事。

## 6. 验收标准（每条都可测）

1. 首屏（y<900）数字 ≤9 个、文本块 ≤80 个，且必须含 1 句非数字结论。
2. 全站最小字号 ≥12px（仅滚动快讯与图表轴允许 10px）。
3. 正文与数字对比度 ≥4.5:1，UI 边框 ≥1.5:1（`scripts/layout_audit.py` 可扩展断言）。
4. 可点目标 ≥32×32（移动端 44×44），且具备 hover / active / focus-visible 三态。
5. 任一卡片 `background` 不得为 `transparent`。
6. 路由切换后 `document.querySelectorAll('[role="dialog"]').length === 0`。
7. 每个专业术语在首屏 1 次点击内可获解释；`--` 出现次数为 0（改为「无数据（原因）」）。
8. 同一含义不得出现两种颜色（止损/目标、统计卡装饰色）。
