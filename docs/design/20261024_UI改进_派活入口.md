## 2. 七条红线（历次事故换来的，违反会返工）

1. **G4 边框用 `#3a3a52`，不是原文的 `#2b2b3f`** —— 后者对比度只有 1.31:1，达不到验收要求的 1.5:1。
2. **改涨红必须三处同步**：`--stock-up` + `--stock-up-hsl: 0 100% 66.1%` + `stock-flash-token.test.ts` 里的 `#E53935` 字面量。漏一处，涨跌闪烁动画会变成「文字新红、底色旧红」——这是 `v0.49.0` 刚修掉的同类 bug。
3. **`locales/zh-CN.ts` 与 `en-US.ts` 是单文件**，19 个目标页面都依赖它。你只能改**自己页面 namespace 块内**的 key；新增顶层 namespace 必须**追加到文件末尾**；**禁止整文件格式化/重排**（会让并行分支必冲突）。
4. **`frontend/src/App.tsx` 只有一个属主**：所有要改它的活（路由默认页 / 全局关 dialog / 顶部 chrome / 标签条 / 侧栏）**必须由同一个 lane 一次做完**，不许拆给两个人。
5. **C3 的页面归属原文写错了**：「净额变化 / 采样数」两列在 `/war-report`，**不在** `/dark-fund-top`。战报页还把同一批 20 只票渲染了 3 遍。处置见 §7.7。
6. **G1 字号是三步走**：第 1 步只建棘轮（不改视觉），第 2 步各 lane 捎带收敛，第 3 步才改 `FONT_ALLOWED`。**第 3 步之前铁律原文（字号六档含 10px）仍然有效**，但不得以"铁律允许"为由拒绝收敛。
7. **`VERSION` / `CHANGELOG.md` / `.github/` 不要动**，发版由主控统一做。
8. **卡片化已翻案（2026-10-24 产品明确）**：只有 **K 线/分时画布** 不包卡片；
   **其余数据模块一律恢复卡片**（底 `--card` 13.5% + 边 ≥1.5:1 + 顶部 1px 高光）。
   此前「hairline 取代边框」的全站口径**作废**。详见勘误 §7.8。
   ⚠️ 别拿 WCAG 对比度判暗色分层 —— 近黑区间会被 `+0.05` 压平（现状卡片/页底只算出 1.08:1，
   但真正的问题是亮度只差 5%）。判据用**绝对亮度差 ΔL ≥8%**。

## 3. 工作方式

```bash
cd /home/ubuntu/sida-pro && git fetch -q origin
git worktree add /home/ubuntu/wt/<lane> -b <branch> origin/main
cd /home/ubuntu/wt/<lane>/frontend && corepack pnpm install --frozen-lockfile   # worktree 无 node_modules
```

- **每路一个 worktree**，绝不共用一个 checkout（git 分支是仓库级的，两个 agent 在同一 checkout 里 `checkout -b` 会互相踩丢改动）。
- **禁止 push / merge**。做完在自己的分支 commit，交主控验收。
- **禁止跑全量 `pytest tests/`**（20+ 分钟）；只跑定向。发版前的 4 分片由主控跑。
- Python 一律 `/home/ubuntu/sida-pro/.venv/bin/python`，命令前缀 `env -u PYTHONPATH`。
  ⚠️ **不要用 `/home/ubuntu/sida-src/.venv`** —— 那是另一个仓库。
- 改完**必须自己 commit**。

```

```
