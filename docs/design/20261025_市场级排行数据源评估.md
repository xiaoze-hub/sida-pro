> **基线标识**：`VERSION = v0.71.0`，commit `4660759`（2026-10-25）。
> **审计对象**：`packages/marketdata/src/marketdata/vendors/tdx.py`（问小达）、`src/collectors/wencai.py`（问财）、

> **覆盖范围**：市场级排行（个股榜 / 板块榜）的**数据源可用性与自建成本**。

| 问题 | 结论 |

## 1. 腾讯排行 API（新发现，免配额零 key）

容器内 `sida` 实测（2026-10-25）：

```
个股榜  https://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList
        ?board_code=aStock&sort_type=PriceRatio&direct=down&offset=0&count=100
        → data.rank_list[]，total=4606

板块榜  https://proxy.finance.qq.com/cgi/cgi-bin/rank/pt/getRank
        ?board_type=hy|gn|dy&sort_type=PriceRatio&direct=down&offset=0&count=100
        → hy 行业 31 个 / gn 概念 805 个 / dy 地区 31 个
```

**字段（个股与板块同构，板块多 `zgb` / `lzg`）**

```
code name zxj(现价) zd(涨跌额) zdf(涨跌幅%) zf(振幅) hsl(换手%) lb(量比) speed(涨速)
turnover(成交额) volume zljlr(主力净流入) zllr zllc zllr_d5 zllc_d5
pe_ttm ltsz(流通市值) zsz(总市值)
zdf_d5 zdf_d10 zdf_d20 zdf_d60 zdf_w52 zdf_y
zgb（板块内 涨/跌 家数，如 "303/334"）  lzg{code,name,zdf,zxj}（领涨股）
```

**参数边界（踩过的坑）**

- `count` **上限 100**，500 直接 KeyError；`offset` 分页正常（`offset=5000` 返回 0 条，不报错 → 分页到底要判空）。
- `sort_type` **白名单**，实测可用：`PriceRatio`(涨幅) / `turnover`(成交额) / `speed`(涨速) / `pn`。
  传 `zdf` / `hsl` / `lb` / `zljlr` / `zsz` 一律 **KeyError 'data'**（响应体没有 data 字段，不是 HTTP 错误）。

### 「主力净流入榜」怎么来

服务端不支持按 `zljlr` 排序，但**每条记录都带 `zljlr`** → 拉全量后本地排序。
805 个概念 = 9 次请求（100/页）。实测结果合理：

```
概念板块 · 主力净流入前5（本地排序）
  人工智能    净流入  99.28亿  涨幅 3.05%  涨跌家数 890/1040  领涨 利亚德 20.00%
  TMT        净流入  77.03亿  涨幅 2.89%  涨跌家数 991/1159
  芯片概念     净流入  75.91亿  涨幅 2.76%  涨跌家数 758/872   领涨 粤芯半导体-U 20.01%
  小米概念     净流入  74.81亿  涨幅 3.45%
  机器人概念    净流入  72.01亿  涨幅 3.39%
```

**这是当前唯一能同时给出「板块涨幅 + 板块资金流 + 板块内涨跌家数 + 领涨股」的免费源。**

## 2. 同花顺问财（`run_wencai`，代码已在仓库）

| 问法 | 实测结果 |
|---|---|
| 今日主力净流入前10的A股 | ✅ 10 行，含 `主力资金流向`、`排名 1/5580`、`最新价`、`最新涨跌幅` |
| 今日涨幅前10的概念板块 | ⚠️ 返回**个股**（每行带 `所属概念` 列），不是板块维度 |
| 今日涨停家数最多的概念板块 | ⚠️ 返回 300 行个股，家数要自己聚合 |

**定位**：个股级排行的兜底源（免配额）；板块级要靠它的 `所属概念` 标签本地聚合，成本高于直接调腾讯。

## 3. 自建（纯本地库）难度评估

| 维度 | 现状 | 判断 |
|---|---|---|
| 全市场日快照 | `more_info_daily` 4,200~5,575 股/日，含 `chg_pct/换手/量比/流通市值` | **但最新只到 2026-10-21**（落后 2 个交易日） |
| 因子横截面排名 | `stock_factor_daily` 90,974 行，已算好 `rank_momentum_20/60` 等 | 覆盖到 2026-10-23（5,247 股），**但没有当日涨跌幅** |
| 涨停池 | `limit_up_events` 10-23 有 53 家，含 `limit_days`/`first_time`/`max_seal_amount` | 个股维度够用 |
| **板块归属** | `stocks` 表**只有 96 行**；涨停 53 家能 join 到的只有 **1 家** | **板块榜的硬卡点** |

**个股榜**：一条 SQL（`more_info_daily` order by `chg_pct` desc）+ 1 个工具 ≈ 2 小时。
**板块榜**：缺行业/概念归属表 → 必须先建 `stock_concept_map` + 全市场采集（问财「所属概念」或腾讯 `board_type=gn` 的成分股），再聚合 → **≥2 天**，且数据仍是滞后的。

**结论：不自建。** 腾讯 API 已经给出实时的、板块+个股全覆盖的数据，自建等于用滞后库重做一遍。

## 4. 建议方案（P1，估 4–6 小时）

新增工具 `get_market_ranking`（注册表 76 → **77**，须同步：`registry.py` / `specs/tools/chat_registry.md` / 3 处钉子测试 / 配方 `budget.max_tool_calls`）。

```
get_market_ranking(scope="stock|industry|concept|region",
                   metric="change|amount|speed|main_inflow",
                   limit=10)
```

- 主源：腾讯排行（`metric=main_inflow` 时拉全量本地排序）
- 兜底：问财 `run_wencai`（个股级；腾讯失败时）
- **口径必须随结果标注**：`腾讯排行 · 实时快照 · 非复权`，且 `zgb` 要写明是「涨/跌家数」**不是涨停家数**（涨停家数仍走 `limit_up_events`，这是两回事，不能混）
- 失败如实报错，不返回 0 条冒充「今天没有」

### 落地顺序

1. `packages/marketdata/src/marketdata/vendors/tencent.py` 加 `fetch_board_rank()`（含分页、`count<=100`、`sort_type` 白名单、本地排序）
2. `registry.py` 加工具（**追加到末尾**，否则 `test_exported_order_is_core_prefix` 索引钉子错位）
3. 测试 ≥10 例：分页到底、`count>100` 不被传、非法 `sort_type` 走本地排序、口径标注、腾讯失败降级问财、全失败如实报错
4. 发版 + 生产实测「今日主力净流入前10的概念板块」
