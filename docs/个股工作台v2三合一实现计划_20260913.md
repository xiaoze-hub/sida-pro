# 个股工作台 v2 三合一 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「行情页 + 盘口页 + 旧个股详情(9 tab)」合并进个股工作台 `/stocks/:symbol`，补齐旧详情内容、同路由内切类型、对每个数据点去重，使工作台成为个股唯一入口。

**Architecture:** 单路由 `/stocks/:symbol?type=stock|index|board&tab=` 承载三类型；页面分三带（顶部信息带 / 首屏 大K + 右栏平铺 / 下部单层标签）。个股 6 标签内容由**从 git `b49263c` 恢复的 `insight/` 组件**承载（复用不重写）；指数/板块正文由既有 `IndexDetail/BoardDetail` **抽成 `IndexBody/BoardBody`** 复用。重复数据点按去重表只留一处。

**Tech Stack:** React 18 + Vite + TS + Tailwind + React Router；pnpm monorepo（`packages/biz-ui`、`packages/api`）；测试 vitest。

**Spec:** `docs/个股工作台v2三合一设计_20260913.md`（两篇都读）。

```ts
export type WorkbenchType = 'stock' | 'index' | 'board'
export type WorkbenchTab = 'l2' | 'suggest' | 'fundamental' | 'news' | 'research' | 'forecast'

export const WORKBENCH_TABS: { id: WorkbenchTab; label: string }[] = [
  { id: 'l2', label: '盘口资金' },
  { id: 'suggest', label: '建议' },
  { id: 'fundamental', label: '基本面' },
  { id: 'news', label: '消息' },
  { id: 'research', label: '研究' },
  { id: 'forecast', label: '预测' },
]

export function normalizeType(v: string | null | undefined): WorkbenchType {
  return v === 'index' || v === 'board' ? v : 'stock'
}

export function parseTab(v: string | null | undefined): WorkbenchTab {
  const hit = WORKBENCH_TABS.find((t) => t.id === v)
  return hit ? hit.id : 'l2'
}

/** 个股专属块(带1 建议条/右栏个股卡/6 标签)仅在 type=stock 显示 */
export function showStockOnly(t: WorkbenchType): boolean {
```

```tsx
function LegacyForecastRedirect() {

}
function LegacyQuoteSymbolRedirect() {
  const { symbol = '' } = useParams()

}
function LegacyL2Redirect() {
  const loc = useLocation()
  const sym = new URLSearchParams(loc.search).get('symbol')
  return <Navigate to={sym ? `/stocks/${encodeURIComponent(sym)}?tab=l2` : '/stocks/000001?type=index'} replace />
}
function LegacyIndexRedirect({ type }: { type: 'index' | 'board' }) {
  const { symbol = '' } = useParams()
  return <Navigate to={`/stocks/${encodeURIComponent(symbol)}?type=${type}`} replace />
```

  ```tsx
  import { useInsightData } from '@panwatch/biz-ui/components/insight/useInsightData'
  import { useInsightDerived } from '@panwatch/biz-ui/components/insight/useInsightDerived'
  import { useInsightActions } from '@panwatch/biz-ui/components/insight/useInsightActions'

  export function InsightProvider({ symbol, market, stockName, hasPosition, children }: {
    symbol: string; market: string; stockName?: string; hasPosition?: boolean; children: React.ReactNode
  }) {
    const props = { open: true, onOpenChange: () => {}, symbol, market, stockName, hasPosition }
    const data = useInsightData(props)
    const derived = useInsightDerived(props, data)
    const actions = useInsightActions(props, data, derived)
    const ctx = useMemo(() => ({ props, ...data, ...derived, ...actions }), [symbol, market])
    return <InsightContext.Provider value={ctx as any}>{children}</InsightContext.Provider>
  }
  ```
- [ ] **Step 2: 惰性门控（关键）**：`useInsightData` 会一次拉 10+ 接口 → **每个标签只在自己的 Provider 内挂载**（`TabPanel` 只渲染当前激活标签，其 Provider 随之挂载/卸载），保证进入工作台不触发下部接口风暴。若 `useInsightData` 内部有必需的 `useEffect` 依赖 `props` 造成全量拉取，则包装成"只拉当前标签所需资源"的薄适配（在 Provider 内加 `enabledKeys`）。
