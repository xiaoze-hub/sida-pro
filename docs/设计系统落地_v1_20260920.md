## 三、未做清单（**明确不做，不是忘了**）

1. **Sparkline 全列表接入**：需要"近 20 日收盘"的**批量接口**；逐行拉 = 持仓 73 行 73 次请求，不可接受。
2. **AlertLog 进右栏**：需要真实事件源（预警触发 / 数据源降级 / 任务完成）；没有事件源的日志 = 摆设。
3. **CaliberBadge / SignalChip 全站扫替**：组件已建好并测过；全站替换属机械活，与本次令牌改动解耦，避免一次 diff 过大。
4. **持仓表 J/K**：`<tr>` 表格需要扁平行模型；机会页（div 行）已接。
5. **设置页的密度/主题/Dim/焦点模式 UI**：命令面板已覆盖；设置页留待与既有外观设置统一。
6. **不做**：外部 CDN、扩大字阶、列表项套卡片、整页会话染色、色觉友好配色的**形状变化**（形状永远不变，只换色）。

## 四、两条方法论（本版踩到的）

1. **写文件后必须立刻复查**：本版有一次 `tailwind.config.js` 补丁"打印成功但文件没变"，
   靠测试（`design-system-tokens.test.ts` 断言 tailwind 含 `s0:`）才暴露 ——
   所以**每处改动都配一条能自己红的断言**，不靠"我记得我改过"。
2. **探针判据必须量"运行时"**：本版把"图表区更空一档"落成"画布不得是纯白"这种**能从像素量出来**的判据，
   而不是"检查 CSS 里有没有这个 token" —— 后者在"token 定义了但没人用"时是假通过。
