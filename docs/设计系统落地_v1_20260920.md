## 四、两条方法论（本版踩到的）

1. **写文件后必须立刻复查**：本版有一次 `tailwind.config.js` 补丁"打印成功但文件没变"，
   靠测试（`design-system-tokens.test.ts` 断言 tailwind 含 `s0:`）才暴露 ——
   所以**每处改动都配一条能自己红的断言**，不靠"我记得我改过"。
2. **探针判据必须量"运行时"**：本版把"图表区更空一档"落成"画布不得是纯白"这种**能从像素量出来**的判据，
   而不是"检查 CSS 里有没有这个 token" —— 后者在"token 定义了但没人用"时是假通过。
