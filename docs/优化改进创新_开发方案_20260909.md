## 0. 总览

### 0.1 目标

1. **先让研究可信**：修掉回测口径、成交约束、因子前视/过拟合、幸存者偏差——修完之前任何策略结论都不作数。
2. **再补数据地基**：复权因子、停牌/ST/退市、K 线校验，让"可回测"成立。
3. **最后做亮点**：因子工厂、事件驱动、LLM 财报解读等创新方向；定位为**实盘辅助**，创新项以"能直接改善盘中决策"为优先。

## 9. 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| 口径变更导致历史结论全变 | 已发布的策略效果数字不可比 | CHANGELOG + UI 文案显式标注；保留旧口径输出为参考字段一版 |
| 新表/迁移影响生产 | 迁移失败或锁表 | 幂等迁移 + 咨询锁 + 迁移前全量备份 + 演练库验证 |
| 因子 OOS 门禁导致权重频繁回退 | 策略行为抖动 | 回退阈值 + 变更审计 + 人工确认窗口 |
| 指标库统一造成前后端数值差异 | 用户看到不同值 | 逐值比对测试（1e-9）先行，前端切换前灰度 |
| 创新方向数据源合规 | 情绪/爬虫类风险 | 只做公开新闻与既有 vendor；不碰反爬与非授权接口 |

**回滚**：每波部署前保留容器快照镜像 + 代码 tar（`docker commit` → 快照镜像；`git archive` 旧 tag），回滚 = 快照重跑 + 旧 env。
