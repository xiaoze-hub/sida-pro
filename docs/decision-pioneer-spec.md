## 关键口径摘要(补差任务的验收基准)
1. **GS策略(主图)**: 多因子趋势跟踪=趋势均线系统+量价背离检测+拐点概率+波段高低点识别; G信号=波段启动(做多/持股), S信号=调整概率(减仓/清仓); G区=上方紫色短柱, S区=绿色短柱; 适合波段/趋势股, 不适合一字板/极阴跌(信号频次低)。
2. **暗盘资金(副图1)**: 按K线形态(OHLC关系)将总成交量分摊买卖量+成交委托单分析净额——**官方原理即OHLC分摊(我方approximation路径同源)**; 红柱=流入/绿柱=流出; 四组合: 涨+红=持股待涨, 跌+绿=回避减仓, 跌+红=底部吸筹重点关注, 涨+绿=诱多警惕减仓。
3. **AI机构活跃度(副图2)**: **6个**技术指标(影线/涨幅/高开等) MAX×1.2; 阈值 1.56生命线/3强势线/6大牛线, **>12更佳**; 紫=非常活跃/红=比较活跃/绿=不活跃; 辅助=连强天+五均。注意: 我方实现为7因子——需核对是否多算一因子。
4. **买入共振**: G信号+暗盘持续红柱+活跃度≥3; **卖出共振**: S信号+暗盘连续绿柱+活跃度快速回落。选股流程: 暗盘流入+活跃度>6(>12更佳)+G区G信号+问财语句。
5. **趋势操盘线**: 红/黄/绿三线; 红黄带=多方/空方带; 买点=升势中回踩多方带收阳 或 回踩绿线收阳; 卖点=跌势中反弹绿线无力突破。
6. **分时突破**: 「突」=盘整>15分钟+突然放量异动+突破日内高点+DDE大单持续流入; 「积」=早盘大单稳健流入积蓄动能(回调买入提示)。
7. **牛熊线**: 牛线=20日加权均线, 马线=5日均线, 买卖线; 金叉=B买入信号, 死叉=S卖出信号。
8. **风险注记**: 指标均有滞后性; 主力可对倒/拆单造假信号; 需多维综合判断。
