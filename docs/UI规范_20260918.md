## 一、分隔：什么用发丝线（hairline），什么用卡片

| 场景 | 用 | 不用 |
|---|---|---|
| 列表 / 表格 / **同一集合的兄弟行**（通知、板块、持仓、任务…） | `divide-y divide-border/40`（发丝线） | 每行自己套 `rounded-* border border-border`（会变成"卡片套卡片"） |
| 独立功能区块（一个模块 / 一张图 / 一个表单） | 卡片：`card` 或 `rounded-xl border border-border/60 bg-card` | 用裸 `border-t` 拼出区块边界 |
| 真表格（Markdown 表、数据网格） | 单元格 `border` + `border-collapse` | —— |
| 输入框 / 下拉 / 按钮 | 自身 `border`（交互元素必须有边界） | —— |

**判断法**：这一层是"一堆同类东西"还是"一个独立东西"？同类 → 发丝线；独立 → 卡片。
**不要**为了统一把已经跑得好的页面重排 —— 规则约束的是**新增代码**与**明显违规**（卡片套卡片）。

## 二、字阶：只留 6 级

| 级 | 用途 |
|---|---|
| `text-[20px]` | 关键大数字（净值、涨跌幅主数值） |
| `text-[16px]` | 页面标题（`h1`） |
| `text-[13px]` | 区块标题 / 强调正文 |
| `text-[12px]` | 正文 / 表格内容（默认） |
| `text-[11px]` | 次要信息（单位、口径说明、时间） |
| `text-[10px]` | 辅助（角标、极简标签） |

**除此以外的 px 字号（9/14/15/17/18/22…）不得新增。** 已有用法按
`scripts/ui-rules-font-baseline.json` **只降不升**（棘轮），改一个少一个；新文件一律 0。

## 三、固定元素（会被别的批次踩到的两条）

1. **固定底部条必须为自身预留空间**（R8）——`fixed inset-x-0 bottom*` 的常驻条（免责声明、状态条）
   必须让内容区补 `padding-bottom`（机制见 `src/index.css` 的 `--disclaimer-h` + `html.has-disclaimer`）。
   踩过的坑：免责条压住 dark-fund-top 表格末行、history 详情、reports 卡片等 **9 页**。
2. **禁止引用外部 CDN**（R9）——`index.html` 不许出现 unpkg/jsdelivr 等外部域。生产实测 CDN 被 CSP/网络
   任意一环拦掉，图表库加载失败 → 主视觉区整块空白。图表库随 `biz-ui` 依赖打包自托管。

## 四、门禁对照（CI 里会红）

| 规则 | 内容 | 实现 |
|---|---|---|
| R6 | `toFixed` 棘轮（格式统一走 `@/lib/format`） | 基线 `scripts/ui-rules-baseline.json` |
| R7 | 禁 `x == null ? 0 : …`（缺数据不许渲染成 0） | 源码扫描 |
| **R8** | 固定底条必须预留空间 | 源码扫描（`disclaimer-h` / `has-disclaimer`） |
| **R9** | `index.html` 禁外部 CDN | 精确匹配 unpkg/jsdelivr |
| **R10** | 字阶棘轮（只允许 6 级，非标准只降不升） | 基线 `scripts/ui-rules-font-baseline.json` |

> 另外两条不在 ui-rules 里、但在同一套"诚实口径"里：① 无数据显示「无数据」+ 原因，**绝不显示 0**；
> ② 涨红跌绿。它们由后端与前端各自的用例钉住（如 `tests/test_caliber_compare.py`、
> `frontend/tests/components/chart-empty.test.tsx`）。
