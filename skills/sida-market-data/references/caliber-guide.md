# 数据口径指南

**这是使用本接口最需要先搞清楚的一件事。**

普通行情 API 只给你一个数字。但资金类数据存在**多个并存的口径**，
不同口径对同一只股票、同一时刻，**数字不同，甚至方向相反**。
用错口径会得出完全反向的结论 —— 而且它不会报错，只会安静地骗你。

本文说明各口径是什么、能用来干什么、以及引用时要注意什么。

---

## 一、两大资金口径：逐笔 vs 按单金额四档

这是最容易踩的坑，也是最常被误用的地方。

### 逐笔主动买卖口径（接口：`get_main_intent`）

按每一笔成交的**主动方向**归类：主动买入算流入，主动卖出算流出，然后加总。

- **含义**：真实反映买卖双方的主动性，具备**方向语义**。
- **用途**：**判断主力意图、吸筹或派发，只能用这个口径。**
- **返回的 `caliber` 字段**会标注这是逐笔口径。

### 按单金额四档归类口径（接口：`get_capital_flow`）

按单笔成交**金额大小**分档：超大单 / 大单 / 中单 / 小单，统计各档净额。

- **含义**：反映**大额资金的参与程度**，但它是"按金额归类"，
  **不等于**这些单子是主动买入还是主动卖出。
- **用途**：作为**资金面参考**，观察大资金活跃度。
- **⚠️ 禁止用途**：**不得据此判定主力意图或吸筹派发。**
  服务端返回中已明确标注：该口径的方向位与逐笔口径可能相反。

### 为什么两者会相反

举个直观例子：主力挂大额卖单，被散户主动买入吃掉 ——
四档口径看到的是"大单流出"，逐笔口径看到的是"主动买入"。
两个数字都对，但描述的是不同的事。

**结论：两个口径的数字必然不同，方向也可能相反。这是正常的，不是数据错误。**

---

## 二、冲突时怎么处理

当两个口径对同一标的给出相反方向时：

1. **一律以逐笔口径为准**（判断方向时）。
2. **在结论中说明口径差异**，而不是只报一个数字。
3. 引用四档口径数据时，**必须并列标注口径来源**，不能让读者误以为那是主力方向。

如果你只是想快速知道"两边是不是打架了"，直接用 `get_main_flow_compare`
（双源主力比对），它会给出并列结果与一致性判断，比自己分别调两个接口再对比省事。

## 三、其它需要留意的口径

### 北向资金（接口：`get_northbound`）—— 估算口径

交易所自 2024 年 8 月起停止披露实时净买入数据。该接口返回的是**估算值**，
返回值中会明确标注。

**不可作为权威数据引用。** 需要判断方向时请用逐笔口径的主力数据。

### DDE 大单口径

同花顺 DDE 是按单逐笔的大单归类，与逐笔口径、按单金额四档口径**都不同**。
同样**不能用于主力意图判定**，只能作资金面参考。

### 合成决策口径

`get_decision_pioneer`（数智决策三指标）是把机构活跃度、技术指标与 L2 主力净流入
**合成**后的结论。它是加工产物，**适合作为参考结论**，若要追溯原始方向仍应回到逐笔口径。

## 四、必须如实标注的三种情况

### 1. 降级

返回中可能出现「降级」「备用源」「暂缺」等标记，表示主数据源不可用、已切换备用源。
**看到这些标记要在结论里如实说明**，不要当作正常数据使用。

### 2. 合规改写

命中合规词时服务端会改写文案，并在 `risk` 字段里标注命中词。
这是服务端行为，不是数据异常。

### 3. 数据缺失

拿不到数据时**如实说明缺什么、为什么缺**。

**绝对不要用其它数据拼凑替代。** 例如缺了竞价数据，不要用开盘价反推一个"竞价榜"出来
—— 这类拼凑产出的结论无法追溯，危害大于"没有数据"。

## 五、返回文本的解析

`result` 是自然语言字符串。格式稳定，可以解析，但**解析前先确认口径与降级标记**。

### get_main_intent

```
主力净{流入|流出}{±X亿}(超大单{±X亿}/大单{±X万|亿}) | 参与度{N}%买占{N}% |
阶段[{阶段文案}] | 竞价{±X万|亿} | 筹码峰{X} 获利{N}% 成本带{A-B}
```

> **读阶段文案要小心**：若同时出现「吸筹」和「派发」（例如 `吸筹后转派发(...)`），
> 意思是该标的**已在获利了结**，不要只看到「吸筹」两个字就当成买入信号。

### get_capital_flow

```
- 主力净{流入|流出} {±X亿}（占比{±N%}）
- 超大单{±X} | 大单{±X} | 中单{±X} | 小单{±X}
```

> 第 2 行与第 5 行是**口径说明文字，不是数据**，解析时要跳过。

### get_technical_analysis

```
技术面：趋势 X，MACD X(n日)，RSI X，支撑位 X，压力位 X，K线形态 X
```

> 去掉前缀后按 `，` 切分，每段按第一个空格拆 key/value。

## 六、引用纪律（写给要把数据转述出去的人）

1. **带口径**：引用资金数据时，把返回的 `caliber` 一并说明。
2. **不加工**：所有返回自带风险提示，转述时保留这个口径，
   **不要把它加工成买卖建议**。
3. **不隐瞒缺失**：降级、估算、缺数据都要说出来。
4. **不单源下结论**：第三方数据服务，准确性与可用性不承诺 SLA。
   关键决策请用第二个数据源交叉验证。

---

## 七、速查

| 你想知道 | 用哪个 | 不能用哪个 |
|---|---|---|
| 主力是流入还是流出 | `get_main_intent`（逐笔） | `get_capital_flow` |
| 是不是在吸筹 / 派发 | `get_main_intent`（逐笔 + 阶段文案） | `get_capital_flow` |
| 大额资金活跃不活跃 | `get_capital_flow`（四档） | — |
| 两个口径有没有打架 | `get_main_flow_compare` | — |
| 北向资金动向 | `get_northbound`（**估算**） | 不要当权威数据 |
| 综合决策参考 | `get_decision_pioneer` | 不要当原始方向依据 |
