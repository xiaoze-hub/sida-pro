## 验收标准

- **REPTREE-001** 序列端点对缺数据交易日必须显式 `available=false`（数值字段全 null），绝不补 0 —— 0 是有效观测值（0 家跌停≠没有数据），补 0 会把「未落库」伪装成「观测为 0」（与 REPLAY-002 同源红线）
- **REPTREE-002** 晋级率出现处必须带三件套：样本数（=上一交易日东财涨停池家数）+ 同池无条件基准（表内未存 → 显式标注口径缺口，禁止省略或编造）+ 是否剔除 T+1 一字涨停（未剔除 → 显式标注，当日一字板家数作旁证）
- **REPTREE-003** 涨停/炸板/跌停家数与晋级率只能标东财三池口径（`eastmoney_zt`，不含北交所）；TQ 全 A 自算（`tq_pool`）同屏出现时必须各自带标签与差值说明（v0.48 实测差 4 家北交所），禁止跨源混算
- **REPTREE-004** 梯队成员明细来自 payload 时受采集截断（Top40，连板高度↓+首封时间↑）：明细不全必须显式标注「明细为已落库 TopN」，且家数以标量列/梯队计数为准；封单额/流通市值比表内未存 → 显式「无数据」，禁止用封单额与流通市值现算冒充
- **REPTREE-005** 分层晋级率（首板→2板→…）表内未存逐层晋级明细 → 端点与 UI 均不得用截断明细现算，必须显式标注口径缺口 —— Top40 截断下现算会静默偏小
- **REPTREE-006** 树端点请求无快照的日期必须返回 `available=false` + `latest_date`（供 UI 提示「最近一期为 YYYY-MM-DD」），情绪周期缺失显式「无数据」，日期一律 YYYY-MM-DD 展示

## 维护方式

新增序列/树字段先在这里补标准再动代码；凡是从 `payload` 里新取的维度，先确认它在
`src/core/market_replay.build_replay` 里怎么截断，再决定是「照实展示」还是「标注缺口」。
